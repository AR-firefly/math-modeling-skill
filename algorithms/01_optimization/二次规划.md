# 二次规划

## 1 适用情况

- 数据要求：目标函数含二次项 0.5 x'Qx + c'x，约束为线性（A x <= b），Q 半正定
- 场景：投资组合优化、带约束最小二乘、凸二次目标求最优
- 何时用：目标有二次曲率、需在资源/范围约束下寻优，变量连续
- 何时不用：目标无二次项（直接用 linprog）、目标非凸（可换差分进化全局搜索）

## 2 可联动算法

- 与无约束解析解对比（KKT/求导），验证约束是否生效
- 非凸二次目标时联动差分进化/粒子群求全局近似
- 参数标定类问题（如 2018A 服装厚度）用 QP 做约束最小二乘

## 3 完整代码模板

```python
"""二次规划：min 0.5 x'Qx + c'x，s.t. A x <= b。"""
import numpy as np


def solve_qp(Q, c, A, b):
    """求解二次规划，返回 (最优解, 最优目标值)。"""
    from scipy.optimize import minimize
    Q = np.asarray(Q, float)
    c = np.asarray(c, float)
    A = np.asarray(A, float)
    b = np.asarray(b, float)
    x0 = np.zeros(Q.shape[0])                      # 初始点

    def obj(x):
        return 0.5 * x @ Q @ x + c @ x

    cons = [{"type": "ineq", "fun": lambda x: b - A @ x}]   # A x <= b
    res = minimize(obj, x0, method="SLSQP", constraints=cons)
    return res.x, res.fun


if __name__ == "__main__":
    # min x1^2 + x2^2 - 4x1 - 4x2，约束 x1 + x2 <= 1
    # 解析解：约束起作用，边界 x1+x2=1 上取极小 → (0.5, 0.5)，最优值 -3.5
    Q = np.array([[2.0, 0.0], [0.0, 2.0]])
    c = np.array([-4.0, -4.0])
    A = np.array([[1.0, 1.0]])
    b = np.array([1.0])
    x, val = solve_qp(Q, c, A, b)
    assert np.allclose(x, [0.5, 0.5], atol=1e-4)   # 与解析解一致
    assert abs(val + 3.5) < 1e-4                   # 最优值 -3.5
    assert A @ x <= b + 1e-6                        # 约束满足
    print("最优解:", x, "最优值:", val)
```

## 4 真题出处

- 二次规划（QP）用于约束最小二乘/二次目标优化：2016A（系泊受力优化）、2018A（服装厚度优化）
- 定位：保底层
