# 博弈论

## 1 适用情况

- 数据要求：多人策略博弈收益表 payoff(m×n×2)（双人有限纯策略，行玩家、列玩家收益）
- 场景：竞争/合作决策、价格竞争、资源博弈、策略均衡分析
- 何时用：参与人策略离散、需找纯策略纳什均衡或混合均衡
- 何时不用：连续策略空间（用最优反应动态/仿真）、无博弈结构（用普通优化）

## 2 可联动算法

- 混合策略纳什均衡可用 scipy.optimize 解线性互补/线性规划
- 动态博弈（序贯决策）可联动动态规划/MDP（2020B 穿越沙漠）
- 与蒙特卡洛仿真对比重复博弈下的长期结果

## 3 完整代码模板

```python
"""博弈论：纯策略纳什均衡搜索（双人有限策略）。"""
import numpy as np


def pure_nash(payoff):
    """payoff(m,n,2)：行玩家收益 payoff[...,0]，列玩家 payoff[...,1]。
    返回纯策略纳什均衡对列表 [(i, j), ...]。"""
    payoff = np.asarray(payoff, float)
    m, n = payoff.shape[:2]
    eq = []
    for i in range(m):
        for j in range(n):
            a = payoff[i, j, 0]
            b = payoff[i, j, 1]
            # 行玩家：当前列 j 下无人愿换到更好的行
            if not any(payoff[k, j, 0] > a + 1e-9 for k in range(m)):
                # 列玩家：当前行 i 下无人愿换到更好的列
                if not any(payoff[i, l, 1] > b + 1e-9 for l in range(n)):
                    eq.append((i, j))
    return eq


if __name__ == "__main__":
    # demo：囚徒困境 2×2（合作/背叛），唯一纯策略纳什均衡为双双背叛 (1,1)
    P = np.zeros((2, 2, 2))
    P[:, :, 0] = [[-1, -3], [0, -2]]     # 行玩家收益
    P[:, :, 1] = [[-1, 0], [-3, -2]]     # 列玩家收益
    eq = pure_nash(P)
    assert (1, 1) in eq                   # 均衡存在
    assert len(eq) == 1                   # 唯一纯策略均衡
    assert P[1, 1, 0] == -2 and P[1, 1, 1] == -2
    print("纯策略纳什均衡:", eq, "均衡收益:", P[1, 1])
```
