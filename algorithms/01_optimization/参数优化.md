# 参数优化

## 1 适用情况

- 数据要求：func 接收参数向量、返回目标（如拟合残差/误差），给定各参数边界 bounds
- 场景：曲线/模型参数标定、单/多参数寻优、最小二乘拟合
- 何时用：模型形式已知、只需定参数（初始值附近光滑收敛）
- 何时不用：目标多峰需全局搜索（换差分进化/模拟退火/网格搜索）、参数有结构性约束（用带约束优化）

## 2 可联动算法

- 作全局算法的精修器：先网格/SA/DE 粗搜，再用 param_opt 局部收敛
- 与差分进化、模拟退火对比，说明"光滑目标用梯度法最快"
- 灵敏度分析：扫描最优参数附近观察目标变化，验证稳定性

## 3 完整代码模板

```python
"""参数优化：scipy.optimize.minimize 局部寻优（L-BFGS-B 带边界）。"""
import numpy as np


def param_opt(func, bounds):
    """func: 接收参数向量；bounds: 各参数 (min, max) 列表。
    返回 (最优参数, 最小目标值)。"""
    from scipy.optimize import minimize
    x0 = np.array([(a + b) / 2 for a, b in bounds])   # 区间中点起步
    res = minimize(func, x0, method="L-BFGS-B", bounds=bounds)
    return res.x, res.fun


if __name__ == "__main__":
    # demo：拟合抛物线 y = a x^2 + b x + c（真实 a=2, b=-3, c=1）
    # 确定性数据，残差平方和最小时参数应精确还原（加噪声仍能逼近）
    x = np.linspace(-2, 2, 20)
    y = 2 * x ** 2 - 3 * x + 1

    def sse(params):
        a, b, c = params
        return float(np.sum((a * x ** 2 + b * x + c - y) ** 2))

    opt, val = param_opt(sse, [(-5, 5), (-5, 5), (-5, 5)])
    assert np.allclose(opt, [2, -3, 1], atol=1e-3)    # 参数误差 < 1e-3
    assert val < 1e-8                                  # 完美拟合残差≈0
    print("拟合参数 a,b,c:", np.round(opt, 4), "残差平方和:", round(val, 4))
```
