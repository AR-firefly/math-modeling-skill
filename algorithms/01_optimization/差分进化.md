# 差分进化

## 1 适用情况

- 数据要求：fitness 函数（最小化）接收连续向量，给定各维边界 bounds
- 场景：连续无梯度优化、多峰/非线性/非光滑目标、参数标定
- 何时用：目标是黑箱、全局搜索、scipy 封装现成（differential_evolution 内建混合全局/局部）
- 何时不用：光滑凸目标（梯度法更快）、离散变量（用 GA/整数规划）

## 2 可联动算法

- 结果作初始点喂给局部优化（L-BFGS）精修
- 与粒子群、模拟退火对比质量与速度，多跑几次报均值±方差
- 参数标定/反演类问题（2025B 干涉反演、2018A）用 DE 做全局初筛

## 3 完整代码模板

```python
"""差分进化（DE）：scipy 封装，全局连续优化。"""
import numpy as np


def de(fitness, bounds, popsize=15, seed=42):
    """fitness: 接收向量；bounds: 各维 (min, max) 列表。返回 (最优解, 最优值)。"""
    from scipy.optimize import differential_evolution
    res = differential_evolution(fitness, bounds, popsize=popsize, seed=seed)
    return res.x, res.fun


if __name__ == "__main__":
    # demo：min f = Σ x_i^2，两维，全局最小 0 在原点
    def sphere(x):
        return float(np.sum(np.asarray(x) ** 2))

    bounds = [(-10, 10), (-10, 10)]
    x, val = de(sphere, bounds, popsize=15, seed=42)
    assert val < 1e-8                  # 收敛到接近全局最优 0
    assert np.linalg.norm(x) < 1e-4    # 解接近原点
    print("最优解:", x, "最优值:", val)
```
