# 排队论

## 1 适用情况

- 数据要求：到达率 λ（单位时间到达数）、服务率 μ（单台单位时间服务数）、服务台数 s，稳态要求 λ < s·μ
- 场景：服务台/等待时间分析、交通流、出租车/安检/医院排队系统
- 何时用：随机到达+随机服务的排队系统，需算排队长度、等待时间
- 何时不用：到达/服务确定性（直接用确定性流量计算）、顾客有优先级（改用仿真）

## 2 可联动算法

- 与蒙特卡洛仿真交叉验证排队指标（解析公式 vs 模拟均值）
- 灵敏度分析：扫描到达率/服务台数观察 Lq/Wq 变化，指导增开服务台
- 系统模拟（2019C 出租车决策）里用排队指标做成本-收益权衡

## 3 完整代码模板

```python
"""排队论：M/M/s 排队模型指标计算（泊松到达 + 指数服务）。"""
import numpy as np
from scipy.special import factorial


def mms_queue(lamb, mu, s=1):
    """到达率 lamb、单台服务率 mu、服务台数 s。
    返回 dict：rho 强度、Lq 平均排队队长、Wq 平均排队时间、L 系统人数、W 逗留时间。"""
    rho = lamb / (s * mu)                        # 每台服务强度，须 < 1
    assert rho < 1, "稳态条件 ρ<1 不满足"
    a = lamb / mu                                # 流量强度
    # 空闲概率 P0
    terms = [a ** k / factorial(k) for k in range(s)]
    p0 = 1.0 / (sum(terms) + a ** s / (factorial(s) * (1 - rho)))
    lq = p0 * a ** s * rho / (factorial(s) * (1 - rho) ** 2)   # 排队队长
    wq = lq / lamb                               # 排队时间
    return {"rho": rho, "Lq": lq, "Wq": wq,
            "L": lq + a, "W": wq + 1 / mu}


if __name__ == "__main__":
    # demo：单服务台 λ=2, μ=3，M/M/1 解析值 Lq=4/3, Wq=2/3
    m = mms_queue(2.0, 3.0, s=1)
    assert abs(m["Wq"] - 2 / 3) < 1e-9           # 与解析公式一致
    assert abs(m["Lq"] - 4 / 3) < 1e-9
    assert m["Wq"] > 0 and m["Lq"] > 0           # 排队时间/队长为正
    print("λ=2, μ=3, M/M/1 → ρ=%.3f Lq=%.4f Wq=%.4f" %
          (m["rho"], m["Lq"], m["Wq"]))
```
