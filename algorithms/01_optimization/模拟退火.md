# 模拟退火

## 1 适用情况

- 数据要求：任意黑箱代价函数 cost(x)，x 为连续/离散向量，不要求可导
- 场景：大规模组合优化、多峰连续优化、布局/调度/路径规划
- 何时用：问题规模大、贪心会陷局部最优、需要全局搜索近似解
- 何时不用：问题规模小且要精确解（用枚举/整数规划）、代价计算极贵（换更少评估的算法）

## 2 可联动算法

- 用贪心/最近邻结果作初始解，加快收敛
- 与遗传算法、粒子群对比求解质量与速度（多跑几次报均值±方差）
- 结尾可加局部搜索（坐标下降）精修

## 3 完整代码模板

```python
"""模拟退火：多峰函数全局最小。"""
import numpy as np


def simulated_annealing(cost, init, T0=100, alpha=0.9, seed=42):
    """cost: 代价函数；init: 初始解（向量）。返回 (最优解, 最优代价)。"""
    rng = np.random.RandomState(seed)
    cur = np.array(init, float)
    best, best_cost = cur.copy(), cost(cur)
    cur_cost = best_cost
    T = T0
    while T > 1e-3:
        for _ in range(20):                                  # 每个温度多次试探
            nxt = cur + rng.randn(len(cur)) * 0.5            # 邻域扰动
            nc = cost(nxt)
            if nc < cur_cost or rng.rand() < np.exp((cur_cost - nc) / T):
                cur, cur_cost = nxt, nc                      # 接受新解（含差解）
                if nc < best_cost:
                    best, best_cost = nxt.copy(), nc
        T *= alpha                                           # 降温
    return best, best_cost


if __name__ == "__main__":
    # 一维多峰函数 f = x^2 - 10cos(2πx) + 10，全局最小在 x=0 处 f=0
    def cost(x):
        return float(x[0] ** 2 - 10 * np.cos(2 * np.pi * x[0]) + 10)

    best, val = simulated_annealing(cost, init=[2.0])
    assert abs(val) < 1.0            # 收敛到接近全局最优 0
    assert abs(best[0]) < 0.5        # 最优解靠近 x=0
    print("最优解:", best, "最优代价:", val)
```
