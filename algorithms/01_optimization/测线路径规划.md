# 测线路径规划

## 1 适用情况

- 数据要求：需遍历的目标点坐标 points(n×2)，起点固定（本模板从点 0 出发）
- 场景：测绘/巡检/无人机测线、物流配送点访问、覆盖式路径规划
- 何时用：目标点已定、求一条走完全部的近似最短路径（TSP 类）
- 何时不用：连续区域覆盖（用扫描线/网格覆盖）、点数大且要精确最优（改 ACO/GA）

## 2 可联动算法

- 贪心最近邻作初始解，再接 2-opt 局部搜索或模拟退火/蚁群精修
- 与 TSP 精确解（小规模枚举）对比近似误差
- 配合多波束覆盖宽度（2023B）在路径上计算重叠率

## 3 完整代码模板

```python
"""测线路径规划：贪心最近邻路径（TSP 近似）。"""
import numpy as np


def route_plan(points):
    """points(n,2) 坐标，从点 0 出发。返回 (总距离, 访问顺序)。"""
    pts = np.asarray(points, float)
    n = len(pts)
    unvisited = set(range(1, n))
    cur, order, total = 0, [0], 0.0
    while unvisited:
        nxt = min(unvisited, key=lambda j: np.hypot(*(pts[cur] - pts[j])))
        total += np.hypot(*(pts[cur] - pts[nxt]))
        unvisited.remove(nxt)
        order.append(nxt)
        cur = nxt
    return total, order


if __name__ == "__main__":
    # demo：8 个随机点，路径覆盖全部点
    rng = np.random.RandomState(42)
    pts = rng.uniform(0, 10, (8, 2))
    total, order = route_plan(pts)
    assert len(order) == 8                     # 访问了全部 8 个点
    assert sorted(order) == list(range(8))     # 每点恰好一次
    assert total > 0
    # 按顺序重算距离与返回值一致
    recalc = sum(np.hypot(*(pts[order[i]] - pts[order[i + 1]]))
                 for i in range(len(order) - 1))
    assert abs(total - recalc) < 1e-9
    print("总距离:", round(total, 3), "访问顺序:", order)
```
