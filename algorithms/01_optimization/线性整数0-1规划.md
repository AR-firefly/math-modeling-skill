# 线性整数0-1规划

## 1 适用情况

- 数据要求：线性目标 + 线性约束（等式/不等式），含整数变量或 0-1 变量（如选址、指派、分配）
- 场景：生产调度、资源分配、路径选择、开关/是否决策类问题
- 何时用：变量必须是整数/布尔且规模不大（几千变量内），需要精确最优解
- 何时不用：变量全连续（用 linprog）、规模超大（转启发式）

## 2 可联动算法

- 连续松弛版用 `linprog` 对比，验证整数约束的必要性
- 大规模整数规划可联动分支定界/遗传算法求近似解
- 0-1 决策可联动多目标优化（ε-约束）处理冲突目标

## 3 完整代码模板

```python
"""线性整数/0-1 规划：scipy.optimize.milp 求解最小化 c'x。"""
import numpy as np


def solve_ip(c, A, b, bounds, integrality):
    """求解整数/0-1 线性规划（最小化 c'x，约束 A x <= b）。
    bounds: 各变量 (min, max) 的 Bounds 对象；integrality: 0=连续，1=整数。
    返回 (最优值, 最优解)。"""
    from scipy.optimize import milp, LinearConstraint
    res = milp(c=np.asarray(c, float), integrality=np.asarray(integrality, int),
               bounds=bounds, constraints=LinearConstraint(A, -np.inf, b))
    return res.fun, res.x


if __name__ == "__main__":
    # demo：max 3x1 + 2x2，x1+x2<=4，2x1+x2<=5，x>=0 整数，唯一最优 (1, 3) 值 9
    from scipy.optimize import Bounds
    c = np.array([-3.0, -2.0])                  # 最大化转最小化
    A = np.array([[1.0, 1.0], [2.0, 1.0]])
    b = np.array([4.0, 5.0])
    bounds = Bounds([0.0, 0.0], [np.inf, np.inf])   # 非负
    integrality = np.ones(2, dtype=int)         # 两个整数变量
    val, x = solve_ip(c, A, b, bounds, integrality)
    assert abs(val + 9.0) < 1e-6                # 最优值 9
    assert np.allclose(x, [1, 3])               # 最优解 (1, 3)
    assert np.all(x == np.floor(x))             # 解确实是整数
    print("最优值:", -val, "最优解:", x)
```
