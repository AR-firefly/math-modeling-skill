# 网格搜索

## 1 适用情况

- 数据要求：func 接收参数元组，给定每个参数的候选取值列表 param_grid
- 场景：参数寻优穷举、小规模组合扫描、作为其他优化的基准
- 何时用：参数空间小、候选值有限、需要穷举保证找到网格内最优
- 何时不用：参数连续/维度高（网格指数爆炸，换随机搜索/贝叶斯/PSO）

## 2 可联动算法

- 作粗筛：先网格搜索定大致区间，再局部优化精修
- 与模拟退火、差分进化对比寻优质量，验证启发式是否优于穷举采样
- 灵敏度分析：固定网格扫描关键参数观察目标变化

## 3 完整代码模板

```python
"""网格搜索：穷举参数组合求最小值。"""
import itertools
import numpy as np


def grid_search(func, param_grid):
    """param_grid: 每个参数的候选值列表。返回 (最优参数元组, 最小值)。"""
    best_params, best_val = None, np.inf
    for comb in itertools.product(*param_grid):   # 全组合穷举
        val = func(comb)
        if val < best_val:
            best_val, best_params = val, comb
    return best_params, best_val


if __name__ == "__main__":
    # demo：min (x-2)^2 + (y+1)^2，两参数各取 101 个网格点
    def f(p):
        x, y = p
        return (x - 2) ** 2 + (y + 1) ** 2

    gx = np.linspace(-5, 5, 101)
    gy = np.linspace(-5, 5, 101)
    params, val = grid_search(f, [gx, gy])
    assert abs(params[0] - 2) < 0.1     # 最优 x ≈ 2
    assert abs(params[1] + 1) < 0.1     # 最优 y ≈ -1
    assert val < 0.1                    # 网格最优点目标值很小
    print("最优参数:", params, "最小值:", round(val, 6))
```
