# 蒙特卡洛

## 1 适用情况

- 数据要求：能写出"单次随机实验"的模拟函数 simulate(rng)，返回一个 0/1 或数值指标
- 场景：系统随机模拟、数值积分（π 估计）、鲁棒性/不确定性评估（参数扰动扫描）
- 何时用：问题含随机因素、解析解难求、需估计概率/期望/分布
- 何时不用：有精确公式（直接解析）、确定性优化（用数学规划）

## 2 可联动算法

- 鲁棒优化：对不确定参数做蒙特卡洛扰动，统计目标值分布（2024C ±10%）
- 系统模拟：生产/交通/排队系统做大量随机试验统计性能（2018B、2019C）
- 灵敏度分析：随机采样参数空间评估响应变化

## 3 完整代码模板

```python
"""蒙特卡洛模拟：统计单次随机实验指标的样本均值。"""
import numpy as np


def monte_carlo(simulate, n=100000, seed=42):
    """simulate(rng): 单次实验返回 0/1 或数值；返回样本均值。"""
    rng = np.random.RandomState(seed)
    return float(np.mean([simulate(rng) for _ in range(n)]))


if __name__ == "__main__":
    # demo：用圆内点占比估计 π
    def in_circle(rng):
        x, y = rng.uniform(0, 1, 2)
        return 1.0 if x * x + y * y <= 1 else 0.0

    pi_est = 4 * monte_carlo(in_circle, n=200000, seed=42)
    assert abs(pi_est - np.pi) < 0.05             # 误差小于 0.05
    assert pi_est > 3.0 and pi_est < 3.3
    print("蒙特卡洛 π ≈", round(pi_est, 4))
```
