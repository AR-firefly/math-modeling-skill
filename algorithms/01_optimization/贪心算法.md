# 贪心算法

## 1 适用情况

- 数据要求：存在明确贪心准则（比值/最大/最省）且能证明局部最优即全局最优（或可接受近似）
- 场景：背包、调度（LPT）、装箱（FFD）、最近邻路径、最小生成树、Huffman 编码
- 何时用：问题具有贪心选择性质、需要快速近似解、或作启发式初始解
- 何时不用：贪心不保证最优且需要精确解（改动态规划/整数规划）

## 2 可联动算法

- 作初始解喂给模拟退火/禁忌搜索/遗传算法（省去随机起步）
- 与 DP/整数规划最优解对比，量化贪心近似误差
- 测线/路径规划类（2023B）用贪心最近邻起步再局部优化

## 3 完整代码模板

```python
"""贪心算法：0-1 背包按价值/重量比贪心。"""
import numpy as np


def greedy_ratio(w, v, W):
    """按价值/重量比从大到小取物品，返回 (总价值, 选中下标)。"""
    w = list(w)
    v = list(v)
    n = len(w)
    order = sorted(range(n), key=lambda i: v[i] / w[i], reverse=True)  # 比值贪心
    cap, tot, pick = W, 0, []
    for i in order:
        if w[i] <= cap:
            cap -= w[i]
            tot += v[i]
            pick.append(i)
    return tot, pick


def greedy_weight(w, v, W):
    """对比用：纯重量贪心（从最轻开始取）。"""
    order = sorted(range(len(w)), key=lambda i: w[i])   # 最轻优先
    cap, tot, pick = W, 0, []
    for i in order:
        if w[i] <= cap:
            cap -= w[i]
            tot += v[i]
            pick.append(i)
    return tot, pick


if __name__ == "__main__":
    # 5 件物品，容量 10：比值贪心取 2 件小件，纯重量贪心只取到 1 件大件
    w = [5, 5, 5]
    v = [6, 6, 9]
    W = 10
    r_tot, r_pick = greedy_ratio(w, v, W)
    wt_tot, _ = greedy_weight(w, v, W)
    assert r_tot == 15                              # 比值贪心 6+9=15
    assert wt_tot == 12                             # 重量贪心 6+6=12
    assert r_tot >= wt_tot                          # 比值贪心不差于重量贪心
    print("比值贪心价值:", r_tot, "选中:", r_pick, "| 重量贪心价值:", wt_tot)
```
