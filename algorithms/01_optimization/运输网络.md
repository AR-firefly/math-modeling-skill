# 运输网络

## 1 适用情况

- 数据要求：单位运输成本矩阵 cost(m×n)、各供应点供给 supply(m)、各需求点需求 demand(n)，供需平衡
- 场景：物资调运、选址配送、网络流/匹配、转运问题
- 何时用：多源多汇线性运输、求最小总运费
- 何时不用：非线性运输成本（用 QP/非线性优化）、带时间窗/车辆约束（用 VRP 启发式）

## 2 可联动算法

- 转化为线性规划（linprog）求解，供需不平衡时加虚拟源/汇
- 与最小费用最大流联动处理带容量中转网络
- 配合 0-1 规划做"选哪些供应商"的顶层决策

## 3 完整代码模板

```python
"""运输网络：供需平衡运输问题求最小运费（线性规划）。"""
import numpy as np


def transport_network(cost, supply, demand):
    """cost(m,n) 单位运费；supply(m) 供给；demand(n) 需求（总供给=总需求）。
    返回 (最小运费, 调运矩阵 m×n)。"""
    from scipy.optimize import linprog
    m, n = cost.shape
    c = cost.flatten()
    A_eq = np.zeros((m + n, m * n))
    for i in range(m):                                  # 每行供给约束
        A_eq[i, i * n:(i + 1) * n] = 1
    for j in range(n):                                  # 每列需求约束
        A_eq[m + j, j::n] = 1
    b_eq = np.r_[np.asarray(supply, float), np.asarray(demand, float)]
    res = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=[(0, None)] * (m * n),
                  method="highs")
    return res.fun, res.x.reshape(m, n)


if __name__ == "__main__":
    # demo：3 供给 × 3 需求，总供给 = 总需求 = 45
    cost = np.array([[2, 3, 1],
                     [5, 4, 8],
                     [3, 2, 6]], float)
    supply = np.array([10, 20, 15], float)
    demand = np.array([15, 15, 15], float)
    fun, X = transport_network(cost, supply, demand)
    assert np.allclose(X.sum(axis=1), supply, atol=1e-6)   # 供给被调空
    assert np.allclose(X.sum(axis=0), demand, atol=1e-6)   # 需求被满足
    assert fun > 0 and np.all(X >= -1e-9)                  # 运费为正、流量非负
    print("最小运费:", round(fun, 4))
    print("调运矩阵:\n", np.round(X, 4))
```
