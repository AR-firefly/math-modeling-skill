# 02 评价类算法索引

> 覆盖：综合评价、分类、聚类、因子分析、统计检验。
> 保底层：对应分析（2022C）、决策分析（并入决策树，2024B）。

| 算法名称                        | 一句话适用场景                               |
| ------------------------------- | -------------------------------------------- |
| [TOPSIS](TOPSIS.md)             | 多指标综合排序，贴近理想解                   |
| [AHP](AHP.md)                   | 层次权重，专家打分（CR<0.1 校验）            |
| [熵权法](熵权法.md)             | 客观权重，离散度大者权重高                   |
| [灰色关联分析](灰色关联分析.md) | 小样本、灰色系统关联度排序                   |
| [模糊综合评价](模糊综合评价.md) | 指标模糊、评语集综合                         |
| [DEA](DEA.md)                   | 多投入多产出效率评价（LP）                   |
| [聚类](聚类.md)                 | 无监督分组（kmeans/层次）                    |
| [判别分析](判别分析.md)         | 已知类别预测新样本（LDA）                    |
| [SVM](SVM.md)                   | 小样本高维分类，含 XGBoost/神经网络（2022C） |
| [朴素贝叶斯](朴素贝叶斯.md)     | 特征独立假设下的快速分类                     |
| [决策树](决策树.md)             | 可解释分类，含决策分析期望收益（2024B）      |
| [随机森林](随机森林.md)         | 稳健分类/特征重要性                          |
| [逻辑回归](逻辑回归.md)         | 二分类概率估计                               |
| [PCA因子分析](PCA因子分析.md)   | 降维/提取主成分（累计>85%）                  |
| [RFM](RFM.md)                   | 客户价值分层（最近/频率/金额）               |
| [Z值判定](Z值判定.md)           | 假设检验/异常值判定                          |
| [组合评价法](组合评价法.md)     | AHP+熵权+CRITIC 权重融合                     |
| [抽样检验](抽样检验.md)         | 小样本推断总体（二项/置信度）                |
| [方差分析](方差分析.md)         | 多组均值差异检验（f_oneway）                 |
| [相关性分析](相关性分析.md)     | 两变量相关（pearson/spearman）               |
| [卡方检验](卡方检验.md)         | 分类变量独立性检验                           |
| [对应分析](对应分析.md)         | 类别间关联结构可视化（2022C 官方讲评核心）   |
| [误差与收敛](误差与收敛.md)     | 网格无关性/收敛阶判定（grid_convergence）    |

> 加分算法并入：强机器学习（XGBoost/LightGBM/神经网络）→SVM.md（2022C）。
