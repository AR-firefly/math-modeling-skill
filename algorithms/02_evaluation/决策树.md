# 决策树

## 1 适用情况

- 数据要求：分类需有标签样本；决策分析需各状态概率与各方案收益矩阵
- 场景：分类规则可视化 + 不确定条件下的期望收益决策
- 何时用：需要可解释的 if-else 决策规则；方案选择需权衡状态概率与收益
- 何时不用：强非线性/高维分类时用随机森林；收益矩阵不可得时不做决策分析

## 2 可联动算法

- 随机森林是决策树集成，精度更高（对应 02 类随机森林.md）
- 决策分析可与蒙特卡洛/期望效用结合，用于方案比选

## 3 完整代码模板

```python
"""决策树：分类 + 期望收益决策分析。"""
import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split
from sklearn.datasets import make_classification


def tree_classify(X, y, depth=3):
    """X: (m, n) 特征；y: (m,) 标签；depth: 最大深度（限制防过拟合）。
    返回拟合好的决策树模型。"""
    return DecisionTreeClassifier(max_depth=depth, random_state=42).fit(X, y)


def decision_analysis(prob, payoff):
    """概率决策：prob (k,) 各状态概率；payoff (m, k) 各方案在各状态收益。
    返回：(各方案期望收益 (m,), 最优方案下标)。"""
    prob = np.asarray(prob, float)
    prob = prob / prob.sum()
    ev = np.asarray(payoff, float) @ prob
    return ev, int(np.argmax(ev))


if __name__ == "__main__":
    # 分类 demo
    X, y = make_classification(n_samples=100, n_features=4, random_state=42)
    Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=42)
    acc = tree_classify(Xtr, ytr).score(Xte, yte)
    assert acc > 0.7
    # 决策分析 demo：两方案 × 三状态（好/中/差）
    prob = [0.3, 0.5, 0.2]
    payoff = np.array([[100, 50, -30], [40, 40, 40]])   # 方案1 冒险、方案2 保守
    ev, best = decision_analysis(prob, payoff)
    assert ev[0] > ev[1] and best == 0                  # 期望收益决策选方案1
    print("决策树准确率:", round(acc, 3), "| 最优方案:", best, "期望收益:", np.round(ev, 1))
```
