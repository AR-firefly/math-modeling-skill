# 判别分析（LDA）

## 1 适用情况

- 数据要求：有类别标签的 m 样本 × n 特征
- 场景：已知类别样本建立判别规则，对新样本归类；也用于降维
- 何时用：类别数较少、线性可分性较好、需要可解释的判别规则
- 何时不用：类别高度非线性可分时用 SVM / 随机森林等更强模型

## 2 可联动算法

- 与聚类搭配：聚类发现类别结构，LDA 验证可分性/建立分类器
- 与 PCA 对比：PCA 无监督降维，LDA 有监督最大化类间/类内距离

## 3 完整代码模板

```python
"""判别分析：线性判别分析 LDA 分类（有监督降维+分类）。"""
import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.model_selection import train_test_split


def lda_fit(X, y):
    """X: (m, n) 特征；y: (m,) 类别标签。返回拟合好的 LDA 模型。"""
    return LinearDiscriminantAnalysis().fit(X, y)


if __name__ == "__main__":
    rng = np.random.RandomState(42)
    X = np.vstack([rng.randn(40, 2) + c for c in [(-2, 0), (2, 0)]])  # 两类线性可分
    y = np.r_[np.zeros(40), np.ones(40)].astype(int)
    Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=42)
    acc = lda_fit(Xtr, ytr).score(Xte, yte)
    assert acc > 0.8                          # 线性可分数据应高准确率
    print("LDA 测试准确率:", round(acc, 3))
```
