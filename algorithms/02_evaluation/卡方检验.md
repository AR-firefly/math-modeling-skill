# 卡方检验

## 1 适用情况

- 数据要求：r×c 列联表（分类变量交叉计数表）
- 场景：检验两个分类变量是否独立（如治疗方案与疗效是否相关）
- 何时用：均为分类/计数数据、要判断独立性或拟合优度
- 何时不用：期望频数过小（<5 的格子较多）时结果不可靠，考虑合并或精确检验

## 2 可联动算法

- 与方差分析、z 检验构成显著性工具箱（对应 02 类方差分析.md、Z值判定.md）
- 显著相关的类别对可结合对应分析可视化（对应 02 类对应分析.md）

## 3 完整代码模板

```python
"""卡方检验：列联表独立性检验。"""
import numpy as np
from scipy import stats


def chi2_test(obs):
    """obs: (r, c) 列联表（非负整数计数）。返回：(卡方统计量, p 值, 自由度, 期望频数)。"""
    return stats.chi2_contingency(obs)


if __name__ == "__main__":
    # demo：2×2 列联表（是否采用新方案 × 结果好坏）
    obs = np.array([[120, 80], [60, 140]])
    chi2, p, dof, expected = chi2_test(obs)
    assert chi2 > 0 and 0 <= p <= 1 and dof == 1     # 2×2 表自由度为 1
    assert expected.shape == obs.shape                # 期望频数形状一致
    print("卡方 =", round(chi2, 3), "| p =", round(p, 4))
```
