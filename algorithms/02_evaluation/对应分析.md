# 对应分析

## 1 适用情况

- 数据要求：r×c 列联表（分类变量的交叉频数表）
- 场景：把行类别与列类别同时投影到低维坐标，可视化类别间关联
- 何时用：多个分类变量（如行业×区域、品牌×评价）需找对应关系、做 biplot
- 何时不用：数值型连续变量用 PCA / 回归更合适；列联表有大量零格时结果不稳

## 2 可联动算法

- 与卡方检验搭配：先验证显著性，再可视化解构关联（对应 02 类卡方检验.md）
- 与 PCA 同属降维家族：对应分析处理计数表、PCA 处理连续矩阵

## 3 完整代码模板

```python
"""对应分析：对列联表做 SVD，提取行/列类别低维坐标。"""
import numpy as np


def correspondence_analysis(X, n_comp=2):
    """X: (r, c) 列联表（非负频数）；n_comp: 提取维数。
    返回：(行坐标 (r, n_comp), 列坐标 (c, n_comp))。"""
    X = np.asarray(X, float)
    P = X / X.sum()                     # 对应矩阵
    r = P.sum(axis=1)                   # 行质量
    c = P.sum(axis=0)                   # 列质量
    # 标准残差矩阵做 SVD，压缩行/列类别差异
    R = (P - np.outer(r, c)) / np.sqrt(np.outer(r, c))
    U, s, Vt = np.linalg.svd(R)
    k = min(n_comp, len(s))
    row = U[:, :k] / r[:, None] * s[:k]      # 行主坐标
    col = Vt[:k].T / c[:, None] * s[:k]      # 列主坐标
    return row, col


if __name__ == "__main__":
    # demo：3×3 列联表（3 区域 × 3 偏好），对角线强关联
    X = np.array([[5, 3, 1], [2, 4, 3], [1, 2, 6]])
    row, col = correspondence_analysis(X, n_comp=2)
    assert row.shape == (3, 2) and col.shape == (3, 2)   # 两维坐标形状正确
    assert np.isfinite(row).all() and np.isfinite(col).all()
    print("行坐标:\n", np.round(row, 3), "\n列坐标:\n", np.round(col, 3))
```
