# 抽样检验（比例检验）

## 1 适用情况

- 数据要求：样本量 n 与成功次数 x（二项总体），需给定原假设比例 θ0
- 场景：合格率/比例检验——判断总体比例是否显著偏离标准（如质检合格率是否达标）
- 何时用：成数型数据（合格/不合格、支持/不支持），大样本近似正态
- 何时不用：样本量小（np 或 n(1-p) < 10）时用二项精确检验

## 2 可联动算法

- 与 z 检验、卡方检验构成显著性检验工具箱（对应 02 类 Z值判定.md、卡方检验.md）
- 结论支撑灵敏度/误差分析中"差异是否显著"判断

## 3 完整代码模板

```python
"""抽样检验：二项总体的比例假设检验（大样本正态近似）。"""
import numpy as np
from scipy import stats


def sampling_test(n, x, theta0, alpha=0.05):
    """n: 样本量；x: 成功（合格）次数；theta0: 原假设合格率；alpha: 显著性水平。
    返回：(z 统计量, p 值, 是否拒绝 H0)。"""
    p_hat = x / n
    z = (p_hat - theta0) / np.sqrt(theta0 * (1 - theta0) / n)   # 比例检验 z 值
    p = 2 * (1 - stats.norm.cdf(abs(z)))
    return z, p, p < alpha


if __name__ == "__main__":
    # demo：抽 200 件产品合格 168 件，检验合格率是否低于 0.9（H1: 低于标准）
    z, p, reject = sampling_test(n=200, x=168, theta0=0.9, alpha=0.05)
    assert 0 <= p <= 1
    assert reject                                     # 0.84 显著低于 0.9，拒绝 H0
    print("z =", round(z, 3), "| p =", round(p, 4), "| 拒绝 H0:", reject)
```
