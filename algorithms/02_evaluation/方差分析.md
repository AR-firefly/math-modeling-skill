# 方差分析（ANOVA）

## 1 适用情况

- 数据要求：多组（≥2）数值样本，组间独立、近似正态、方差齐性
- 场景：单因素方差分析——判断多组均值是否存在显著差异
- 何时用：比较三个以上处理/分组的效果（如不同方案产量是否不同）
- 何时不用：只有两组时用 t 检验等价；方差不齐时用 Welch 校正或非参检验

## 2 可联动算法

- 与 z 检验、卡方检验构成显著性工具箱（对应 02 类 Z值判定.md、卡方检验.md）
- 两两比较配合 Tukey HSD（scipy.stats.tukey_hsd）找差异来源

## 3 完整代码模板

```python
"""方差分析：单因素 ANOVA 检验多组均值差异。"""
import numpy as np
from scipy import stats


def anova_test(groups):
    """groups: 各组样本列表，如 [g1, g2, g3]（每组为数组）。
    返回：(F 统计量, p 值)。"""
    return stats.f_oneway(*groups)


if __name__ == "__main__":
    rng = np.random.RandomState(42)
    g1 = rng.normal(10, 2, 20)                # 三组均值依次抬高
    g2 = rng.normal(12, 2, 20)
    g3 = rng.normal(14, 2, 20)
    F, p = anova_test([g1, g2, g3])
    assert np.isfinite(F) and 0 <= p <= 1
    assert p < 0.05                            # 组间均值差异显著
    print("F =", round(F, 3), "| p =", round(p, 4))
```
