# 朴素贝叶斯

## 1 适用情况

- 数据要求：有类别标签的 m 样本 × n 特征（特征条件独立假设）
- 场景：快速概率分类，输出各类别后验概率
- 何时用：特征多、样本量小、需要概率解释；文本分类等场景
- 何时不用：特征强相关时独立性假设破坏，分类精度下降，改用判别模型

## 2 可联动算法

- 与 SVM / 决策树做精度对比，验证模型稳定性
- 后验概率可作软标签喂给组合评价/决策分析

## 3 完整代码模板

```python
"""朴素贝叶斯：GaussianNB 高斯朴素贝叶斯分类。"""
import numpy as np
from sklearn.naive_bayes import GaussianNB
from sklearn.model_selection import train_test_split
from sklearn.datasets import make_classification


def bayes_classify(X, y):
    """X: (m, n) 特征；y: (m,) 标签。返回拟合好的 GaussianNB 模型。"""
    return GaussianNB().fit(X, y)


if __name__ == "__main__":
    X, y = make_classification(n_samples=100, n_features=4, n_informative=3,
                               n_redundant=0, n_classes=2, random_state=42)
    Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=42)
    acc = bayes_classify(Xtr, ytr).score(Xte, yte)
    assert acc > 0.7
    print("朴素贝叶斯测试准确率:", round(acc, 3))
```
