# 模糊综合评价

## 1 适用情况

- 数据要求：m 方案 × n 评语的隶属度矩阵（每行和为 1），评语权重已知
- 场景：评价等级语义模糊、难以精确打分时，用隶属度表达程度
- 何时用：评语是"优/良/中/差"等模糊等级、专家给隶属度
- 何时不用：指标可精确量化时直接用 TOPSIS 等更精确

## 2 可联动算法

- 权重可来自 AHP / 熵权法（对应 02 类 AHP.md、熵权法.md）
- 与 TOPSIS 结合：模糊隶属度定定性指标，TOPSIS 做定量排序

## 3 完整代码模板

```python
"""模糊综合评价：加权模糊合成评判各方案。"""
import numpy as np


def fuzzy_eval(R, w):
    """R: (m, n) 隶属度矩阵（m 方案，n 评语，每行和为 1）；w: (n,) 评语权重。
    返回综合评价值 (m,)，值越大方案越优。"""
    R = np.asarray(R, float)
    w = np.asarray(w, float) / np.asarray(w, float).sum()
    return R @ w                            # 加权平均合成算子


if __name__ == "__main__":
    # demo：3 方案 × 4 评语（优/良/中/差）的隶属度矩阵
    R = np.array([
        [0.6, 0.3, 0.1, 0.0],               # 方案1 集中在"优"
        [0.3, 0.4, 0.2, 0.1],               # 方案2 集中在"良"
        [0.1, 0.2, 0.3, 0.4],               # 方案3 集中在"差"
    ])
    w = np.array([0.4, 0.3, 0.2, 0.1])      # 评语权重：优>良>中>差
    score = fuzzy_eval(R, w)
    assert score.shape == (3,) and (score >= 0).all() and (score <= 1).all()
    assert score[0] > score[1] > score[2]   # 越靠"优"评价值越高
    print("综合评价值:", np.round(score, 3))
```
