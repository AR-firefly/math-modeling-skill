# 灰色关联分析

## 1 适用情况

- 数据要求：多对象 × 多指标的数值序列，需确定一个参考序列（如各指标最优值）
- 场景：测度比较序列与参考序列的相似（关联）程度，小样本、少数据也适用
- 何时用：数据量小、分布规律不明显，需考察整体贴近度
- 何时不用：指标间强相关且需精确度量时，用回归/相关性分析更合适

## 2 可联动算法

- 与 TOPSIS 对比：TOPSIS 看距离、灰关联看相似度，可互为验证
- 权重可由熵权法/AHP 给定后做加权关联度

## 3 完整代码模板

```python
"""灰色关联分析：度量比较序列与参考序列的相似程度。"""
import numpy as np


def grey_relational(X, ref, rho=0.5):
    """X: (m, n) 比较序列；ref: (n,) 参考序列（各指标最优值）；rho: 分辨系数。
    返回关联度向量 (m,)，值在 0-1，越大越贴近参考。"""
    X = np.asarray(X, float)
    ref = np.asarray(ref, float)
    # 均值化消除量纲
    X = X / X.mean(axis=0, keepdims=True)
    ref = ref / ref.mean()
    delta = np.abs(X - ref)                  # 绝对差序列
    dmin, dmax = delta.min(), delta.max()
    # 关联系数，再按行平均得关联度
    coeff = (dmin + rho * dmax) / (delta + rho * dmax)
    return coeff.mean(axis=1)


if __name__ == "__main__":
    rng = np.random.RandomState(42)
    ref = rng.rand(3) * 10 + 5
    X = ref + rng.randn(4, 3) * 0.5          # 4 个比较序列围绕参考波动
    r = grey_relational(X, ref)
    assert (r >= 0).all() and (r <= 1).all()  # 关联度在 0-1
    closest = int(np.argmin(np.abs(X - ref).sum(axis=1)))
    assert r[closest] == r.max()              # 最贴近参考的关联度最高
    print("灰色关联度:", np.round(r, 3))
```
