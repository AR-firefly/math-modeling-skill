# 熵权法

## 1 适用情况

- 数据要求：m 方案 × n 指标的决策矩阵（数值型，越大越好/越小越好先做正向化）
- 场景：客观定权重——指标信息熵越小（变异越大）含信息越多，权重越大
- 何时用：无主观偏好、需要纯数据驱动权重
- 何时不用：指标值接近均匀（熵大）时权重趋同，失去区分意义

## 2 可联动算法

- 权重喂给 TOPSIS / 模糊综合评价 / 灰色关联做综合评价
- 与 AHP 主客观结合，用组合评价法融合（`combine_weights`）

## 3 完整代码模板

```python
"""熵权法：信息熵确定客观权重。"""
import numpy as np


def entropy_weight(X):
    """X: (m, n) 决策矩阵（m 方案，n 指标，已正向化）。
    返回客观权重向量 w (n,)，和为 1、非负。"""
    X = np.asarray(X, float)
    P = X / (X.sum(axis=0, keepdims=True) + 1e-12)   # 各指标内归一化；分母加小量防全零列除零
    P = np.clip(P, 1e-12, 1)                  # 防 log(0)
    m = P.shape[0]
    e = -np.sum(P * np.log(P), axis=0) / np.log(m)   # 信息熵（0-1）
    d = 1 - e                                # 差异系数：越大信息越多
    w = d / d.sum()
    return w


if __name__ == "__main__":
    # demo：4 方案 × 3 指标决策矩阵
    rng = np.random.RandomState(42)
    X = rng.rand(4, 3) * 10
    w = entropy_weight(X)
    assert np.isclose(w.sum(), 1) and (w >= 0).all()
    print("熵权:", np.round(w, 3))
```
