# 相关性分析

## 1 适用情况

- 数据要求：两组数值变量（或一个变量的多列）
- 场景：度量两变量线性相关（Pearson）或单调相关（Spearman）的方向与强度
- 何时用：找指标间的关联、筛选自变量、检验共线性
- 何时不用：要量化"因"与"果"关系时用回归/因果模型，相关≠因果

## 2 可联动算法

- 相关系数矩阵进聚类/PCA 做指标去冗余（对应 02 类聚类.md、PCA因子分析.md）
- 与回归分析搭配：相关显著则建回归模型

## 3 完整代码模板

```python
"""相关性分析：Pearson 与 Spearman 相关系数。"""
import numpy as np
from scipy import stats


def corr_pearson(X, Y):
    """X, Y: (n,) 两组数据。返回 (Pearson 系数, p 值)。"""
    return stats.pearsonr(X, Y)


def corr_spearman(X, Y):
    """X, Y: (n,) 两组数据。返回 (Spearman 系数, p 值)。"""
    return stats.spearmanr(X, Y)


if __name__ == "__main__":
    rng = np.random.RandomState(42)
    x = rng.randn(50)
    y = 2 * x + rng.randn(50) * 0.5          # 构造强正相关数据
    rp, pp = corr_pearson(x, y)
    rs, ps = corr_spearman(x, y)
    assert rp > 0.8 and rs > 0.8             # 两种系数都显著为正
    assert 0 <= pp <= 1 and 0 <= ps <= 1
    print("Pearson =", round(rp, 3), "| Spearman =", round(rs, 3))
```
