# 组合评价法

## 1 适用情况

- 数据要求：至少两套权重向量（如 AHP 主观 + 熵权/CRITIC 客观），长度一致
- 场景：主客观权重融合——平衡专家偏好与数据信息，避免单一方法片面
- 何时用：主观法数据少、客观法过度依赖样本时，融合更稳健
- 何时不用：已有明确可信的单一权重来源时不必组合

## 2 可联动算法

- 上游：AHP（`ahp_weight`）、熵权法（`entropy_weight`）、CRITIC
- 下游：组合权重喂给 TOPSIS / 模糊综合评价 / 灰色关联

## 3 完整代码模板

```python
"""组合评价法：融合主观 + 客观权重，加权平均归一化。"""
import numpy as np


def combine_weights(methods, alpha=None):
    """methods: 权重向量列表（如 [AHP, 熵权, CRITIC]），每个长度为 n 且元素非负。
    alpha: 各方法信任权重（默认等权）。返回组合权重 (n,)，和为 1。"""
    W = np.asarray(methods, float)
    W = W / W.sum(axis=1, keepdims=True)             # 各方法分别归一化
    if alpha is None:
        alpha = np.ones(W.shape[0]) / W.shape[0]
    alpha = np.asarray(alpha, float) / alpha.sum()
    w = alpha @ W                                    # 加权平均融合
    return w / w.sum()


if __name__ == "__main__":
    ahp = np.array([0.5, 0.3, 0.2])                  # 主观：AHP
    ent = np.array([0.25, 0.45, 0.30])               # 客观：熵权
    cri = np.array([0.33, 0.33, 0.34])               # 客观：CRITIC
    w = combine_weights([ahp, ent, cri])
    assert np.isclose(w.sum(), 1) and (w >= 0).all()
    print("组合权重:", np.round(w, 3))
```
