# 聚类分析

## 1 适用情况

- 数据要求：m 样本 × n 特征的数值矩阵，无标签
- 场景：无监督分组——把样本分成若干簇，簇内相似、簇间相异
- 何时用：数据量大、类别未知，或先分群再做分群评价
- 何时不用：有明确类别标签时用判别/分类方法；样本太少时聚类不稳定

## 2 可联动算法

- 聚类后对每簇分别评价，配合 TOPSIS / DEA 做组内排序
- 簇数 k 用肘部法/轮廓系数确定；与判别分析搭配：聚类发现群、LDA 验证可分性

## 3 完整代码模板

```python
"""聚类：KMeans 与层次聚类。"""
import numpy as np
from sklearn.cluster import KMeans, AgglomerativeClustering


def cluster(X, k=3, method="kmeans"):
    """X: (m, n) 样本；k: 簇数；method: 'kmeans' 或 'hierarchical'。
    返回标签向量 (m,)，取值 0..k-1。"""
    X = np.asarray(X, float)
    if method == "kmeans":
        return KMeans(n_clusters=k, n_init=10, random_state=42).fit_predict(X)
    return AgglomerativeClustering(n_clusters=k).fit_predict(X)


if __name__ == "__main__":
    # demo：3 个中心不同的高斯簇合成数据
    rng = np.random.RandomState(42)
    X = np.vstack([rng.randn(30, 2) + c for c in [(0, 0), (5, 5), (0, 5)]])
    lab = cluster(X, k=3)
    assert len(np.unique(lab)) == 3          # 恰好分成 3 簇
    assert np.bincount(lab).min() > 20       # 各簇样本量合理
    print("簇计数:", np.bincount(lab))
```
