# 误差与收敛分析

## 1 适用情况

- 数据要求：两组不同网格步长下的数值结果（数值解与精确解误差）
- 场景：网格收敛性检验——验证数值格式收敛阶、证明结果网格无关
- 何时用：数值积分/差分/有限元等离散化方法，需报告收敛阶和误差随网格细化行为
- 何时不用：无精确解对照时改用 Richardson 外推或相邻网格比值法

## 2 可联动算法

- 与灵敏度分析配合，构成"数值正确性"检验（网格无关性验证是评分要点）
- 收敛阶结合误差分析支撑论文"数值收敛"章节

## 3 完整代码模板

```python
"""误差与收敛阶：由两组步长与误差估算数值格式收敛阶。"""
import numpy as np


def grid_convergence(h1, h2, r1, r2):
    """h1, h2: 两种网格步长（h1 > h2）；r1, r2: 对应数值误差。
    返回收敛阶 p = log(r1/r2) / log(h1/h2)。"""
    return np.log(r1 / r2) / np.log(h1 / h2)


if __name__ == "__main__":
    # demo：梯形积分逼近 e^x 在 [0,1] 的积分，理论收敛阶为 2
    f = lambda x: np.exp(x)
    a, b = 0.0, 1.0

    def trap(h):
        n = int(round((b - a) / h))
        x = np.linspace(a, b, n + 1)
        return h * (f(x).sum() - 0.5 * (f(x[0]) + f(x[-1])))   # 梯形公式

    h1, h2 = 0.1, 0.05
    exact = np.exp(1) - 1
    r1, r2 = abs(trap(h1) - exact), abs(trap(h2) - exact)
    p = grid_convergence(h1, h2, r1, r2)
    assert p > 1.5                          # 实测收敛阶接近理论值 2
    print("收敛阶 p =", round(p, 3))
```
