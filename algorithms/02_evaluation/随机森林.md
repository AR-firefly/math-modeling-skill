# 随机森林

## 1 适用情况

- 数据要求：有类别标签的 m 样本 × n 特征（可处理混合/缺失特征）
- 场景：集成多棵决策树投票分类，精度高、抗过拟合，自带特征重要性
- 何时用：分类精度优先、特征较多需排序筛选
- 何时不用：需要严格可解释单规则时用单棵决策树；样本极小集成意义有限

## 2 可联动算法

- 决策树是基学习器（对应 02 类决策树.md）
- 特征重要性用于指标筛选，可进相关性/回归分析

## 3 完整代码模板

```python
"""随机森林：集成多棵决策树分类，含特征重要性。"""
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.datasets import make_classification


def rf_classify(X, y, seed=42):
    """X: (m, n) 特征；y: (m,) 标签；seed: 固定随机种子保证可复现。
    返回拟合好的随机森林模型（含 feature_importances_）。"""
    return RandomForestClassifier(n_estimators=100, random_state=seed).fit(X, y)


if __name__ == "__main__":
    X, y = make_classification(n_samples=100, n_features=6, n_informative=5,
                               n_redundant=0, random_state=42)
    Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=42)
    model = rf_classify(Xtr, ytr)
    acc = model.score(Xte, yte)
    assert acc > 0.8                                  # 集成模型精度高
    assert model.feature_importances_.shape == (X.shape[1],)   # 特征重要性可输出
    print("随机森林准确率:", round(acc, 3),
          "| 特征重要性:", np.round(model.feature_importances_, 3))
```
