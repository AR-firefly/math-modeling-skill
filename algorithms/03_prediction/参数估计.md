# 参数估计

## 1 适用情况

- 数据要求：样本观测数据 + 假定分布/模型结构，待估参数未知
- 场景：极大似然（MLE）或最小二乘估计分布参数、反演机理模型参数
- 何时用：已知分布族或模型解析式、需从数据反推参数、系统辨识
- 何时不用：模型结构未知（先拟合/分解再定结构）、样本过少（先评估可识别性）

## 2 可联动算法

- Logistic增长模型 / 机理建模：MLE 估计其参数（curve_fit 即最小二乘特例）
- 误差/灵敏度分析：参数估计的置信区间、对估计的扰动分析
- 假设检验：估计后做分布拟合优度检验

## 3 完整代码模板

```python
"""极大似然估计（MLE）：负对数似然 + 数值优化估计正态参数。"""
import numpy as np
from scipy.stats import norm
from scipy.optimize import minimize


def mle_fit(data, dist="norm"):
    """data: 样本；dist: 分布名（当前支持 norm）。返回极大似然参数 [mu, sigma]。"""
    data = np.asarray(data, float)
    if dist == "norm":
        # 最大化对数似然等价于最小化负对数似然
        def neg_log_lik(theta):
            mu, sigma = theta
            return -norm.logpdf(data, loc=mu, scale=sigma).sum()
        res = minimize(neg_log_lik, [data.mean(), data.std()],
                       method="Nelder-Mead", options={"xatol": 1e-6})
        return res.x
    raise ValueError(f"暂不支持分布: {dist}")


if __name__ == "__main__":
    rng = np.random.RandomState(42)
    data = rng.normal(loc=2.0, scale=3.0, size=2000)  # 从 N(2, 3) 采样
    mu, sigma = mle_fit(data, "norm")
    assert abs(mu - 2.0) < 0.5, "均值估计应接近真值 2"
    assert abs(sigma - 3.0) < 0.5, "标准差估计应接近真值 3"
    print(f"MLE 估计: mu={mu:.3f}, sigma={sigma:.3f}（真值 2, 3）")
```
