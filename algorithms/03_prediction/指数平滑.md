# 指数平滑

## 1 适用情况

- 数据要求：单变量时间序列，趋势平稳或带轻微趋势/季节
- 场景：快速、稳健的短期预测，对近端数据加权更大
- 何时用：无剧烈结构变化、需要简单快速的外推、样本不多
- 何时不用：强季节（改用时间序列分解.md + 季节指数平滑）、强非线性（改用 ARIMA / Logistic）

## 2 可联动算法

- 时间序列分解：先季节调整再做指数平滑
- ARIMA：同为平滑预测，对比择优（趋势稳定时指数平滑更快）
- 灵敏度：平滑系数 α、β、γ 影响近远端权重，可做参数扫描

## 3 完整代码模板

```python
"""Holt-Winters 指数平滑：带趋势的平滑预测（SimpleHoltWinters 兼容）。"""
import numpy as np
from statsmodels.tsa.holtwinters import ExponentialSmoothing


def holt_winters(series):
    """series: 一维序列。返回拟合对象与未来 10 期预测。"""
    series = np.asarray(series, float)
    model = ExponentialSmoothing(series, trend="add", seasonal=None, damped_trend=True)
    fit = model.fit()                       # 自动优化平滑系数
    pred = fit.forecast(10)
    return fit, np.asarray(pred)


if __name__ == "__main__":
    rng = np.random.RandomState(42)
    t = np.arange(40, dtype=float)
    y = 0.3 * t + 2.0 * np.sin(0.6 * t) + rng.randn(40) * 0.5  # 趋势 + 波动
    fit, pred = holt_winters(y)
    assert len(pred) == 10, "预测长度应为 10"
    assert np.all(np.isfinite(pred)), "预测值必须有限"
    print("Holt-Winters 预测:", np.round(pred, 2))
```
