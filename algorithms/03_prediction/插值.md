# 插值

## 1 适用情况

- 数据要求：已知离散点 (x_i, y_i)，需在区间内任意 x 处取值
- 场景：加密采样点、补齐缺测、网格化（测线/地形重建）
- 何时用：已知点准确、需过点平滑补值；拉格朗日少点时用，样条更稳定
- 何时不用：点含噪声应拟合（用线性多元回归.md）而非过点插值、x 超出采样范围（外推风险大）

## 2 可联动算法

- 参数估计：与曲线拟合对比，插值过点、拟合滤噪
- 数值积分/微分：插值后对连续函数积分求面积
- 可视化：加密点画平滑曲线

## 3 完整代码模板

```python
"""插值：拉格朗日多项式 / 三次样条（CubicSpline）。"""
import numpy as np
from scipy.interpolate import CubicSpline


def interp_lagrange(x, y, xx):
    """拉格朗日插值：通过全部 n 个已知点的 n-1 次多项式。"""
    x = np.asarray(x, float); y = np.asarray(y, float); xx = np.asarray(xx, float)
    n = len(x)
    res = np.zeros_like(xx)
    for i in range(n):
        L = np.ones_like(xx)
        for j in range(n):
            if i != j:
                L *= (xx - x[j]) / (x[i] - x[j])    # 拉格朗日基函数
        res += y[i] * L
    return res


def interp_spline(x, y, xx):
    """三次样条插值：分段三次多项式，光滑且更稳定。"""
    cs = CubicSpline(np.asarray(x, float), np.asarray(y, float))
    return cs(np.asarray(xx, float))


if __name__ == "__main__":
    x = np.linspace(0, 2, 7)                # 7 个已知采样点
    y = np.sin(x)
    xx = np.linspace(0, 2, 500)             # 待插值位置
    err_l = np.abs(interp_lagrange(x, y, xx) - np.sin(xx)).max()
    err_s = np.abs(interp_spline(x, y, xx) - np.sin(xx)).max()
    assert err_l < 1e-3, "拉格朗日插值误差应 < 1e-3"
    assert err_s < 1e-3, "样条插值误差应 < 1e-3"
    print(f"拉格朗日最大误差={err_l:.2e}, 样条最大误差={err_s:.2e}")
```
