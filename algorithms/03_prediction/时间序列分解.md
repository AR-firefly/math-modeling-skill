# 时间序列分解

## 1 适用情况

- 数据要求：单变量时间序列，含趋势 + 季节 + 随机波动，周期已知（如月度 12）
- 场景：拆出趋势/季节/残差三部分，分别分析或预测
- 何时用：有明显季节周期、需剥离噪声看趋势走向、季节调整
- 何时不用：无周期、纯趋势（直接指数平滑 / 回归）

## 2 可联动算法

- ARIMA：对分解后的趋势/残差分别建模型预测
- 指数平滑：季节项已知后，可对季节调整序列做平滑
- 灰色预测GM11：小样本下只对趋势分量做灰色预测

## 3 完整代码模板

```python
"""时间序列分解：趋势 + 季节 + 残差（加法模型）。"""
import numpy as np
from statsmodels.tsa.seasonal import seasonal_decompose


def seasonal_decompose_(series, period=12):
    """series: 一维序列；period: 季节周期（如 12 月）。
    返回 decompose 结果，含 trend / seasonal / resid。"""
    series = np.asarray(series, float)
    res = seasonal_decompose(series, model="additive", period=period)
    return res


if __name__ == "__main__":
    rng = np.random.RandomState(42)
    t = np.arange(120, dtype=float)                  # 10 年月度数据
    y = 0.1 * t + 3.0 * np.sin(2 * np.pi * t / 12) + rng.randn(120)  # 趋势+季节+噪声
    res = seasonal_decompose_(y, period=12)
    # 各组件形状与原序列一致（趋势两端为 NaN）
    assert res.trend.shape == y.shape
    assert res.seasonal.shape == y.shape
    assert res.resid.shape == y.shape
    print("趋势/季节/残差形状:", res.trend.shape,
          "季节振幅约", round(np.nanmax(res.seasonal), 2))
```
