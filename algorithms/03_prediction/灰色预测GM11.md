# 灰色预测GM11

## 1 适用情况

- 数据要求：小样本（n ≥ 4）单调递增/递减序列，无长期季节波动
- 场景：数据量少、规律不强、不宜建统计模型时的短期预测
- 何时用：样本 4~10 个、要求快速外推、序列近似指数规律
- 何时不用：数据非单调或波动大、需要长周期预测（改用 ARIMA.md / 时间序列分解.md）

## 2 可联动算法

- 时间序列分解：先分离趋势再用 GM(1,1) 拟合趋势段
- 残差检验：回代残差 < 5% 视为模型可靠（本文 demo 校验）
- 与 ARIMA 对比：小样本用 GM(1,1)，样本足用 ARIMA

## 3 完整代码模板

```python
"""GM(1,1) 灰色预测：小样本单调序列的一阶累加建模预测。"""
import numpy as np


def gm11(x, n_future=5):
    """x: 原始序列；n_future: 外推期数。
    返回预测全序列，长度 len(x)+n_future，前 len(x) 个是回代拟合值。"""
    x = np.asarray(x, float)
    n = len(x)
    x1 = np.cumsum(x)                       # 一次累加生成，弱化随机性
    # 紧邻均值序列 z(k) = 0.5*(x1(k)+x1(k+1))
    z = -0.5 * (x1[:-1] + x1[1:])
    B = np.column_stack([z, np.ones(n - 1)])
    Y = x[1:]
    a, b = np.linalg.lstsq(B, Y, rcond=None)[0]   # 最小二乘求发展系数 a、灰作用量 b
    # 累加序列预测：x1_hat(k) = (x(1)-b/a) * exp(-a(k-1)) + b/a
    k = np.arange(n + n_future)
    x1_hat = (x[0] - b / a) * np.exp(-a * k) + b / a
    x_hat = np.empty(n + n_future)
    x_hat[0] = x1_hat[0]
    x_hat[1:] = np.diff(x1_hat)             # 累减还原
    return x_hat


if __name__ == "__main__":
    x = np.array([3.1, 3.4, 3.7, 4.0, 4.4, 4.8, 5.3, 5.8, 6.4, 7.0])  # 单调递增小样本
    pred = gm11(x, n_future=5)
    assert len(pred) == len(x) + 5, "预测长度应为 n + n_future"
    assert np.all(np.isfinite(pred)), "预测值必须有限"
    rel_err = np.abs(pred[:len(x)] - x) / x     # 回代拟合残差
    assert np.all(rel_err < 0.05), "历史残差应 < 5%"
    print("历史残差最大:", round(rel_err.max(), 4), "未来5期:", np.round(pred[-5:], 3))
```
