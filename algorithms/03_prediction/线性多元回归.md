# 线性多元回归

## 1 适用情况

- 数据要求：n 个样本 × p 个自变量的数值矩阵 X（无强多重共线性），连续因变量 y
- 场景：量化多自变量对因变量的影响、趋势预测、因素重要性排序
- 何时用：关系近似线性、样本量 > 自变量数、需要可解释的系数
- 何时不用：自变量高度共线（改用主成分回归PLS.md）、关系非线性（改用 Logistic 或多项式回归）

## 2 可联动算法

- 主成分回归PLS：X 强共线时先提取主成分再回归
- 正交试验/DOE（2021B）：以因素-水平设计矩阵为 X、指标为 y，回归拟合效应模型
- 显著性检验（statsmodels OLS 的 t 值/P 值）筛掉不显著因素
- 灵敏度分析：对系数做参数扰动看预测变化

## 3 完整代码模板

```python
"""线性多元回归：最小二乘拟合 + K 折交叉验证。"""
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import cross_val_score


def reg_fit(X, y, cv=5):
    """X: (n, p) 自变量；y: (n,) 因变量。
    返回：模型、训练 R²、交叉验证 RMSE（应为有限值）。"""
    X = np.asarray(X, float)
    y = np.asarray(y, float)
    model = LinearRegression()
    model.fit(X, y)                       # 最小二乘拟合系数
    r2 = model.score(X, y)                # 训练集 R²
    # 交叉验证：负均方误差取反开根号得 RMSE
    cv_mse = -cross_val_score(model, X, y, cv=cv, scoring="neg_mean_squared_error")
    cv_rmse = float(np.sqrt(cv_mse.mean()))
    return model, r2, cv_rmse


if __name__ == "__main__":
    rng = np.random.RandomState(42)
    X = rng.randn(50, 3)                  # 50 样本、3 特征
    y = 2.0 * X[:, 0] + 3.0 * X[:, 1] - 1.0 * X[:, 2] + rng.randn(50) * 0.1
    model, r2, cv_rmse = reg_fit(X, y)
    assert r2 > 0.5, "线性关系拟合优度 R² 应较高"
    assert np.isfinite(cv_rmse), "CV-RMSE 应为有限值"
    print(f"R2={r2:.3f}, CV-RMSE={cv_rmse:.3f}, 系数≈{[round(c, 2) for c in model.coef_]}")
```
