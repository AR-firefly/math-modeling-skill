# 马尔可夫链预测

## 1 适用情况

- 数据要求：离散状态系统的转移概率矩阵（行和为 1）+ 初始状态分布
- 场景：状态只与当前有关（无后效性）的短期转移预测，如天气、市场占有率
- 何时用：状态有限、可统计转移频数、关心长期平稳分布
- 何时不用：状态连续（用回归/时间序列）、未来依赖历史全过程（非马尔可夫）

## 2 可联动算法

- 数据清洗/统计：由观测序列频数统计转移矩阵
- 蒙特卡洛仿真：马尔可夫链作为仿真中状态转移发生器
- 动态规划/博弈：与状态转移相关的问题（如 2020B 穿越沙漠）

## 3 完整代码模板

```python
"""马尔可夫链：状态转移概率矩阵预测各期状态分布。"""
import numpy as np


def markov_predict(trans_matrix, init, n):
    """trans_matrix: (s, s) 转移矩阵（行和为 1）；init: 初始分布；n: 预测期数。
    返回 (n+1, s)，第 i 行是第 i 期的状态分布（i=0 为初始）。"""
    T = np.asarray(trans_matrix, float)
    p = np.asarray(init, float)
    p = p / p.sum()                         # 归一化初始分布
    probs = [p.copy()]
    for _ in range(n):
        p = p @ T                           # 一步转移：p(t+1) = p(t) T
        probs.append(p.copy())
    return np.array(probs)


if __name__ == "__main__":
    T = np.array([[0.6, 0.3, 0.1],
                  [0.2, 0.5, 0.3],
                  [0.1, 0.2, 0.7]])         # 3 状态转移矩阵（行和为 1）
    init = np.array([0.5, 0.3, 0.2])
    probs = markov_predict(T, init, n=20)
    assert np.allclose(probs.sum(axis=1), 1.0), "各期概率和应为 1"
    assert np.allclose(probs[-1], probs[-2], atol=1e-6), "应收敛到平稳分布"
    print("平稳分布:", np.round(probs[-1], 4))
```
