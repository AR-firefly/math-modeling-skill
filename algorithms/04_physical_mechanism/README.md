# 04 机理类算法索引

> 覆盖：物理机理建模、ODE/PDE 数值解、信号处理、几何与定位。
> 保底层：运动学动力学（2016A~2025A）、光学干涉太阳几何（2025B/2023A）。

| 算法名称                                | 一句话适用场景                                          |
| --------------------------------------- | ------------------------------------------------------- |
| [运动学动力学](运动学动力学.md)         | 抛体/刚体/振动等运动建模（2016A~2025A）                 |
| [ODE数值解](ODE数值解.md)               | 常微分方程组数值解，含反应动力学/多物理场（RK4/odeint） |
| [有限差分热传导](有限差分热传导.md)     | 热传导偏微分显式差分（CFL<0.5）                         |
| [数值积分](数值积分.md)                 | 定积分/多重积分（梯形/Simpson/Gauss）                   |
| [FFT周期提取](FFT周期提取.md)           | 频域分析/周期提取（振动、波形）                         |
| [Radon变换](Radon变换.md)               | 断层扫描/投影重建，含图像重建（2017A）                  |
| [坐标变换](坐标变换.md)                 | 旋转/平移/坐标系转换                                    |
| [几何建模](几何建模.md)                 | 距离/面积/空间几何关系计算                              |
| [最小二乘拟合](最小二乘拟合.md)         | 曲线/曲面参数拟合（curve_fit）                          |
| [三角测量定位](三角测量定位.md)         | 已知角度/距离反推位置（GPS/测向）                       |
| [光学干涉太阳几何](光学干涉太阳几何.md) | 太阳高度角/光线/干涉条纹（2025B/2023A）                 |

> 多自由度/多物理场耦合→ODE数值解.md（2022A）；化学反应动力学→ODE数值解.md（2021B）；
> 微分/差分方程建立→ODE数值解.md（2016A~2024A）。
