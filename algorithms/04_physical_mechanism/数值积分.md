# 数值积分

## 1 适用情况

- 数据要求：被积函数或离散采样点、积分区间 [a, b]
- 场景：面积/体积/弧长/工作量计算，连续函数定积分无解析解时
- 何时用：函数连续可采样、需要固定精度；Simpson 对光滑函数精度高
- 何时不用：被积函数带奇点/间断（分段或换高斯求积）

## 2 可联动算法

- 有限差分热传导：总热量/总质量用积分校验
- 运动学动力学：位移=速度积分
- 三角测量定位：圆弧/扇形面积等几何量积分

## 3 完整代码模板

```python
"""数值积分：梯形法 / Simpson 法。"""
import numpy as np


def integral(f, a, b, method="simpson", n=100):
    """f: 被积函数；a, b: 区间端点；method: 'trapezoid'|'simpson'。
    返回定积分近似值。"""
    x = np.linspace(a, b, n + 1)
    y = f(x)
    if method == "trapezoid":
        h = (b - a) / n
        return h * (0.5 * y[0] + y[1:-1].sum() + 0.5 * y[-1])
    elif method == "simpson":
        assert n % 2 == 0, "Simpson 需偶数等份"
        h = (b - a) / n
        return h / 3 * (y[0] + y[-1] + 4 * y[1:-1:2].sum() + 2 * y[2:-1:2].sum())
    raise ValueError(f"未知方法: {method}")


if __name__ == "__main__":
    # demo：sin 在 [0, π] 积分 = 2
    f = np.sin
    s = integral(f, 0, np.pi, method="simpson", n=100)
    t = integral(f, 0, np.pi, method="trapezoid", n=100)
    assert abs(s - 2) < 1e-2, f"Simpson 误差 {abs(s-2)}"
    assert abs(t - 2) < 1e-2, f"梯形误差 {abs(t-2)}"
    print(f"Simpson={s:.6f}，梯形={t:.6f}，解析值 2")
```
