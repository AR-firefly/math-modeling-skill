# 最小二乘拟合

## 1 适用情况

- 数据要求：自变量 x、观测 y、带参数的模型函数 f(x; θ)
- 场景：非线性参数估计——指数衰减、logistic、多参数经验公式
- 何时用：模型形式已知（物理/经验公式）、只需估参数
- 何时不用：模型形式未知（用插值/机器学习）；线性模型用 lstsq 更快

## 2 可联动算法

- ODE 数值解：先数值解 ODE 再用本算法拟合动力学参数
- FFT 周期提取：FFT 给初频，curve_fit 精调幅相
- 有限差分热传导：由温度序列反推热扩散系数 alpha

## 3 完整代码模板

```python
"""非线性最小二乘拟合：scipy.optimize.curve_fit。"""
import numpy as np
from scipy.optimize import curve_fit


def ls_fit(x, y, model, p0=None):
    """model: 模型函数 f(x, *params)；x, y: 观测数据。
    返回 (拟合参数数组, 协方差矩阵)。"""
    x = np.asarray(x, float)
    y = np.asarray(y, float)
    return curve_fit(model, x, y, p0=p0)


if __name__ == "__main__":
    # demo：拟合 y = a·e^(b·x) + c，真值 a=2, b=-1, c=0.5
    rng = np.random.RandomState(42)
    model = lambda x, a, b, c: a * np.exp(b * x) + c
    x = np.linspace(0, 1, 30)
    y_true = 2 * np.exp(-1 * x) + 0.5
    y = y_true + 1e-4 * rng.randn(len(x))        # 轻微噪声
    p, _ = ls_fit(x, y, model, p0=[1, 0, 0])
    resid = np.max(np.abs(model(x, *p) - y_true))
    assert resid < 1e-3, f"拟合残差 {resid} 过大"
    assert abs(p[0] - 2) < 1e-2 and abs(p[2] - 0.5) < 1e-2
    print(f"拟合参数 a={p[0]:.4f}, b={p[1]:.4f}, c={p[2]:.4f}，残差={resid:.2e}")
```
