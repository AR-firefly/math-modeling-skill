# 有限差分热传导

## 1 适用情况

- 数据要求：一维温度场初始分布、热扩散系数 alpha、网格/时间步长
- 场景：热传导/扩散过程——温度场随时间演化、物质浓度扩散
- 何时用：规则网格、线性扩散、需要显式迭代且步长可控
- 何时不用：复杂几何/高维强耦合（改有限元或隐式格式）

## 2 可联动算法

- ODE 数值解：把空间离散后的方程视作半离散 ODE 统一推进
- 数值积分：总热量守恒校验用求和/积分
- 最小二乘拟合：由实测温度序列反推热扩散系数 alpha

## 3 完整代码模板

```python
"""一维热传导显式差分：T 内点按 CFL 条件迭代更新，边界保温（Neumann）。"""
import numpy as np


def heat_explicit(T0, alpha=0.01, dt=0.005, dx=0.1, steps=100):
    """T0: 初始温度分布数组；alpha: 扩散系数；dt/dx: 时间/空间步长。
    返回推进 steps 步后的温度分布。"""
    T = np.asarray(T0, float).copy()
    cfl = alpha * dt / dx ** 2
    assert cfl < 0.5, f"CFL={cfl} 必须<0.5 否则不稳定"
    for _ in range(steps):
        T[1:-1] += cfl * (T[2:] - 2 * T[1:-1] + T[:-2])   # 三点中心差分
    return T


if __name__ == "__main__":
    # demo：初始高斯峰，扩散后应展宽、降温、总热量不变
    x = np.arange(0, 5 + 1e-9, 0.1)              # dx=0.1
    T0 = 1 + 10 * np.exp(-((x - 2.5) / 0.5) ** 2)
    T = heat_explicit(T0, alpha=0.01, dt=0.005, dx=0.1, steps=100)
    assert abs(T.sum() - T0.sum()) < 1e-8, "温度不守恒"      # 总和不变
    assert T.max() < T0.max(), "峰未展宽"                    # 扩散降温
    cfl = 0.01 * 0.005 / 0.1 ** 2
    assert cfl < 0.5                                         # CFL 校验
    print(f"总热量守恒偏差={abs(T.sum()-T0.sum()):.2e}，峰值 {T0.max():.3f}->{T.max():.3f}")
```
