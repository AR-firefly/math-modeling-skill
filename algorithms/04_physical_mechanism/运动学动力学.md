# 运动学动力学

## 1 适用情况

- 数据要求：初速度、抛射角等参数，或可抽象为质点运动的几何位置关系
- 场景：抛体/轨道/质点运动——已知初速与角度求射程、高度、轨迹
- 何时用：运动可视为理想抛体、忽略空气阻力或可用解析解快速逼近
- 何时不用：需计空气阻力/变质量的复杂动力学（改走 ODE 数值解.md）

## 2 可联动算法

- ODE 数值解：计入空气阻力时把运动方程交 RK4 求解
- 有限差分/数值积分：求运动过程的位移积分或时间积分
- 三角测量定位：由观测角度反推运动体位置

## 3 完整代码模板

```python
"""抛体运动：已知初速 v0 与抛射角 theta（度），返回轨迹与射程。"""
import numpy as np


def projectile(v0, theta, g=9.81, dt=1e-3):
    """v0: 初速度(m/s)；theta: 抛射角(度)；g: 重力加速度。
    返回 (x, y) 轨迹数组，含落地终点（y=0）。"""
    th = np.radians(theta)
    vx, vy = v0 * np.cos(th), v0 * np.sin(th)
    T = 2 * vy / g                      # 对称抛体落地时间
    t = np.arange(0, T, dt)
    x = vx * t
    y = vy * t - 0.5 * g * t ** 2
    x = np.append(x, vx * T)            # 补落地终点
    y = np.append(y, 0.0)
    return x, y


if __name__ == "__main__":
    # demo：45° 抛射，理论上射程 = v0²/g（45° 射程最大）
    v0 = 10.0
    x, y = projectile(v0, 45.0)
    rng = (x[-1] - v0 ** 2 / 9.81) / (v0 ** 2 / 9.81)   # 相对误差
    assert abs(rng) < 0.01, f"射程误差过大: {rng}"
    # 最高点高度 = (v0 sin45)² / 2g
    ymax = (v0 * np.sin(np.radians(45))) ** 2 / (2 * 9.81)
    assert abs(y.max() - ymax) < 1e-6
    print(f"45° 射程={x[-1]:.4f}m（理论 {v0**2/9.81:.4f}m），最高点={y.max():.4f}m")
```
