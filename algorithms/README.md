# 算法库（algorithms/）—— 四大类全量算法

> 用途：编程手在赛题求解时的**算法检索 → 打开详情 → 复制代码模板**。
> 每个算法一个 `.md`，含"1 适用情况 / 2 可联动算法 / 3 完整代码模板（可运行 demo+assert）/ 4 真题出处"。
> 所有代码模板可独立运行：`seed=42` 自包含、无阻塞调用、不依赖外部下载。

## 四大类

| 类        | 目录                     | 数量 | 覆盖题型                                       |
| --------- | ------------------------ | ---- | ---------------------------------------------- |
| 01 优化类 | `01_optimization/`       | ~21  | 规划/组合优化/元启发式/图论/排队/博弈/参数寻优 |
| 02 评价类 | `02_evaluation/`         | ~23  | 综合评价/分类/聚类/统计检验/因子分析           |
| 03 预测类 | `03_prediction/`         | ~10  | 回归/时间序列/灰色系统/马尔可夫/插值           |
| 04 机理类 | `04_physical_mechanism/` | ~11  | 物理机理建模/ODE/偏微分/信号/几何              |

## 阅读顺序（编程手）

1. **读题 → 判断题型**：赛题属于哪一类（优化/评价/预测/机理），打开对应类的 `README.md` 索引
2. **索引表检索**：按"一句话适用场景"定位算法
3. **打开算法详情**：读"1 适用情况"确认数据要求与场景匹配
4. **复制代码模板**：把"3 完整代码模板"的 `solve_xxx` 函数拷到赛题代码，改输入即可
5. **联动**：看"2 可联动算法"是否要组合（如 TOPSIS 联动熵权定权重）

## 目录用途注释

- `algorithms/README.md` —— 本导航页
- `algorithms/0X_*/README.md` —— 每类索引表（算法名可跳转）
- `algorithms/0X_*/*.md` —— 每个算法详情（模板见上）
- `tests/test_algorithm_catalog.py` —— 全量校验脚本（每个 .md 代码块 compile + demo exec）
