# 数学建模竞赛论文写作心法

> 现行阶段、来源、创新、人工声明及交付边界见 `../references/执行与交付契约.md`；原细则在当前阶段范围内执行，不代替团队第一问批准或全文独立终审。


## 核心原则

1. **标题规则**：直接用原题标题，不用"基于XX"式命名
2. **摘要总分总**：总开头（问题+方法）→ 按实际问题分段（每问一段，含结果）→ 总结尾（价值+延伸）
3. **加粗策略**：结果数据（数值）、模型名、关键发现——三者必加粗
4. **关键字**：4-5个，从摘要加粗的模型名中抽取

## 论文结构（原四问13节参考，按实际问数组织）

| 序号   | 章节                 | 要点                                                                    |
| ------ | -------------------- | ----------------------------------------------------------------------- |
| 封面   | 参赛论文封面         | 按当年官方规范处理，匿名评阅论文不得含身份信息                                |
| 摘要   | 摘要                 | **总分总**，每问一段，结果加粗                                          |

| 三     | 模型假设             | 数量按模型需要，逐条给依据和失效条件                                  |

| 十二   | 附录                 | 文件清单+核心代码                                                       |

## 建模部分规范

### 优化模型的标注形式

**必须包含**：

1. 决策变量定义
2. 目标函数（min/max + 公式）
3. 约束条件（逐条列出）
4. **大括号汇总**：将所有公式归入一个大括号环境

### 算法描述分层

- 元启发式算法必须有伪代码或步骤说明
- 精确算法给出核心转移方程
- 基线对比必须说明

### 禁止"吊书袋"

- 算法名称为**问题服务**，不堆砌
- 不罗列同类算法对比表（除非做消融实验）
- 评价算法的词不超过3个

## 内容铁律

| 规则                   | 说明                                  |
| ---------------------- | ------------------------------------- |
| 标题不修饰             | 不用"基于XX"、"XX改进"等前缀          |
| 分析不出结果           | 问题分析只讲思路，结果在求解部分给出  |
| 假设以简化为主         | 数量按必要性决定，不能省略关键假设与依据 |
| 分级不超过三级         | 一、→ 1.1 → （1），不继续往下         |
| 公式单独一行           | 行内公式可用，重要公式必须独立成行    |
| 表题在表上、图题在图下 | 表1在上，图1在下（表上图下）          |
| 无吊书袋               | 不出无意义的算法罗列                  |
| 字数控制               | 摘要≤1页，正文≤30页，附录不限         |

## 交付前四轮自审（论文手必做，门禁4 检查）

论文全文完成后**必须**按四轮顺序自审，每轮通过才进下一轮；❌ 修复后重审。四项全部完成；这是四个审查维度，不是终审返工次数上限。

| 轮次             | 查什么                                                                         | 不通过的例子 → 怎么改                                     |
| ---------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------- |
| **一、论证逻辑** | 每个主张有证据支撑（能追到 results/ 数据）；无悬空主张、跳跃逻辑、循环论证     | "本模型精度高"但没有数值 → 补上对应 results 数字并解释    |
| **二、章节结构** | 摘要六要素（背景/思路/每问方法+结果/检验/关键词）；每问"建模→求解→检验"完整    | 某问只有模型没有检验 → 补该问灵敏度/误差分析              |
| **三、表述质量** | 对照 `references/去AI味写作.md` 八类 AI 痕迹逐条扫描 + 数据准确性复核          | 全文"首先/其次/最后"模板化 → 按类别替换，数据核对 results |
| **四、格式规范** | 图编号与正文一一对应、表上图下、参考文献与正文引用一致、页数达标、符号说明表全 | 图3 正文没提 / 引了 [5] 但列表没有 → 修正对应关系         |

> 门禁4 仍由**独立 Subagent** 对照以上 + 国赛评审维度审计（references/Subagent质检.md）。四轮自审是论文手写完后自己的把关，不是替代门禁。

## 摘要与全文质量补充

摘要必须明确建立何种模型、采用何种求解算法、各问关键数值及实际含义和检验结论；区分模型与算法。全文重点是模型合理性、算法、结果、解释、灵敏度。文字图表各自自足并互补，所有图表有正文解释。AI声明和详情正文留空、提示独立人工待办。阅读全文证据、TRIZ时机、固定标准无轮数双审见统一契约。
