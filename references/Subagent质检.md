# Subagent 质检：门禁 2a/2b（共七节点）成功标准

> 现行阶段、来源、创新、人工声明及交付边界见 `执行与交付契约.md`；原细则在当前阶段范围内执行，不代替团队第一问批准或全文独立终审。

> 每个门禁由**独立 Subagent 审计**——给成功标准，不给步骤（防止自己又当选手又当裁判）。
> Subagent 对照以下标准检查产物，报告差距，不回填步骤。
> 门禁4（论文质量）、门禁5（process_record）为标准定义，与 SKILL.md 门禁定义一致。

## 门禁0 文献先行（建模手产出 → 文献调研报告）

> 禁令（SKILL.md AI 行为边界第一条）：**AI 禁止靠知识库拍脑袋解题**——核心选择须有既有文献或原创推导与验证依据。
> 独立 Subagent 对照 `references/文献调研报告模板.md` 检查：

- [ ] **多源检索真实**：报告记录了 本地匹配优秀论文 / 允许学术原始来源 检索（实际采用的允许来源可查，未取得的证据标待核验），失败如实标待核验，不切换排除来源
- [ ] **六维评分执行**：有评分表，题型匹配 gate（<10 自动拒）已执行，总分 = 六维之和（无 subagent 虚高）
- [ ] **逐篇文献卡片**：每篇含 来源 / 方法 / 借鉴点 / 怎么用
- [ ] **核心建模选择预登记完整**：每问计划方法 ↔ 文献出处一一对应
- [ ] **核心依据完整**：已有方法引用，原创选择的推导和独立验证计划完整，不能仅凭经验定案
- [ ] **检索证据卡片可查**：`docs/检索证据卡片/` 中证据轨卡片可查，与报告引用、核心建模选择预登记一一对应；`docs/情报/` 不作为证据或判据来源

**通过标准**：报告真实、核心选择有既有文献或原创推导与验证依据；**既有方法补原出处；原创推导须依据及独立验证**；检索证据卡片可查，阻断在门禁1 之前。

## 门禁1 建模定稿（建模手产出 → 建模文档）

独立 Subagent 检查建模文档是否含以下全部内容：

- [ ] **① 每问题型判断**：每个子问题明确判断为 优化/评价/预测/机理 四类之一，
      并定位到 algorithms/ 索引的保底/加分算法
- [ ] **② 模型假设清单**：每条假设编号、内容、简化了什么、何时不成立
- [ ] **③ 模型结构**：决策变量、目标函数、约束条件（可写成公式）
- [ ] **④ 每问求解思路与预期结果**：用什么算法、预期输出什么数字
- [ ] **追加 · 核心建模选择必论证必对比**：核心判定/模型定义（如遮蔽判定方式）从题面物理本质推导并写明理由；至少一个替代方案的数值对比（确认简化不改变结论，由编程手门禁1 后执行回填）；每条简化假设注明失效条件（先证明再算）
- [ ] **追加 · 15 维度适配性 + 真伪创新 + 网红模型规避**：逐条过 问题适配/复杂度/真伪创新/假设/数据/求解/验证/可解释/背景契合/多模型对比/误差不确定性/推广/参数依据/逻辑表达/代码复现（**去分值**）；创新区分真伪（换名字、堆算法=伪；有依据、有效果、可验证=真）；**不选网红模型，按题适配优先**。创新可从五个方向找（**不是必须全占，能落一个真实有效的即可**）：参数自适应（随数据/环境自动调参）、多模型对比择优（不拍脑袋选，用数值比出来）、求解算法升级（同模型换更强解法且有量化收益）、同领域融合（把本题特有机理引进来）、跨领域迁移（借其他领域的成熟建模框架）
- [ ] 无未澄清歧义（模糊点已列入"人工审核方向"）

**通过标准**：以上 6 项全绿 + 核心建模选择有论证，无"待定/未澄清"阻塞项。

## 门禁2a 代码可跑（编程手产出 → results/ + 检验）

> 阶段机检只检查当前已授权范围；pytest/self-test为Skill工具回归，真实赛题证据由独审实际检查。`--project` 仍**仅限全文审计**；第一问阶段的产物检查改用 `scripts/stage_gate.py --stage q1`。
> 独立 Subagent 在此基础上复核（可实际运行验证），不可机检项由主Agent自审和独立Agent语义审查，团队另行做方向及最终提交决定：

- [ ] **工具回归基线（维护时在临时副本验证）**：`examples/` 下 main.py（优化）、评价\_TOPSIS_demo、预测\_GM11_demo、机理\_ODE_demo 全部可运行
- [ ] **工具测试基线（不代赛题验收）**：`python -m pytest tests/ -v` 无失败（含 test_algorithm_catalog 全量校验算法库）
- [ ] **当前赛题五类检验**：当前已授权问题实际执行 网格无关/数值收敛/灵敏度/误差分析/对比验证（逐项评估适用性，N/A有理由并独审认可）；**对比验证须含核心建模选择的替代方案数值对比**（非仅改进前后对比，含多场景/多方法对比 ≥3 组）
- [ ] **results 为赛题真解**：results/ 结果是按赛题数据真解算出（非 run_all demo 占位骨架，非通用占位实现）
- [ ] **seed=42 固定**：随机算法可复现；`run_manifest.json` 含 seed 与输入文件 SHA-256
- [ ] **算法代码可独立运行**：algorithms/ 每个 .md 的代码块 demo 可 exec（检查实际测试覆盖与跳过项，不以测试名声称全部数学正确）

> **作图脚本预检（validate_figures）已移出本门禁**，归 `门禁2b 图可复现`，不在 2a 重复检查；2b 保留原项原文。

**通过标准**：全部可跑 + pytest 全绿 + 五样检验有据可查。

## 门禁2b 图可复现（作图手产出 → figures/）

> 与 2a 由**两个独立 Subagent** 分审；作图脚本预检自 2a 移入本门禁，不在 2a 重复。
> 独立 Subagent 须**实际运行脚本并独立看图**，不得只看作图手记录；机检不替代目视。

- [ ] **脚本可独立复现**：`figures/scripts/*.py` 在**空 cwd** 子进程独立运行并产出 PNG（脚本 `__file__` 相对定位，不依赖 run_all）
- [ ] **无统计推断**：脚本无 `np.std/var/percentile/quantile/corrcoef`、`scipy.stats.*`、`curve_fit/least_squares`、sklearn `.fit()/.predict()`（AST 静态 + 运行时守卫双拦；豁免须注明非空理由）
- [ ] **契约齐全**：每图含脚本 + 数据入口 + PNG + `figures_manifest.json` 条目（含 `data_binding` 与 CONTRACT 元数据），路径为相对路径且一律正斜杠
- [ ] **画图脚本过 validate_figures 预检**：figures/ 绘图脚本跑 `scripts/validate_figures.py` 静态预检（中文字体/禁 rainbow/jet/hsv/DPI≥300），FAIL 已修（对照 `references/图表规范.md` §五）
- [ ] **图数值与 results 一致**：插桩捕获实际绘图入参，经 `data_binding` 解析到 `results/q1_results.json`（q1）/ `results.json`（final）实际键值，逐值比对一致
- [ ] **目视检查**：每张图实际打开查看（数值与图注一致/坐标轴含单位/图例完整不遮挡/无裁切溢出/灰度与色盲可辨/中文无乱码/面板编号正确）；审查 Agent 必须**独立看图**，`docs/log_审查.md` 须写作图手记录中未出现的独立观察项，与作图手记录完全一致且无独立观察视为未独立查看

**通过标准**：脚本空 cwd 独立跑通产出 PNG + 无统计推断 + 契约齐全 + 图数值与 results 一致 + 目视检查有记录。

## 门禁4 论文质量（论文手产出 → paper 写作质量）

独立 Subagent 对照**三层自评（硬门槛 + 官方四维度 + 检查项，不含任何分值、不作获奖等级预测）+ 往年优秀论文写法框架 + 国赛评审维度**，审论文写作质量：

- [ ] 摘要总分总 / 每问一段 / 结果加粗（对照 `methodology/写作心法.md`）
- [ ] 按实际问题数组织完整章节结构 / 表上图下 / 分级≤三级（对照 `methodology/写作心法.md`）
- [ ] 图表编号与正文对应 / 300dpi / 关键结论有图承载（对照 `references/图表规范.md` + `methodology/process_record规格.md` §7）
- [ ] 核心模型有物理论证（先证明再算：能推导为什么这样、不拍脑袋）+ 简化假设失效条件（对照门禁1「核心建模选择必论证必对比」）
- [ ] 每问结果有物理合理性解释（量级/几何/趋势说得通，对照国赛评审「结果符合物理常识」）
- [ ] **四轮自审已执行**：论文手交付前跑完四轮自审（论证逻辑→章节结构→表述质量→格式规范，`写作心法.md`），第三轮已对照 `references/去AI味写作.md` 扫 AI 痕迹
- [ ] **三层自评已执行**：第一层硬门槛（查重 25% / AI 使用声明与详情 PDF / 摘要专用页 ≤1 页 / 正文 ≤30 页 / 附录含全部可运行源码 / 无身份信息 / 竞赛纪律，一票否决）+ 第二层官方四维度（假设合理性 / 建模创造性 / 结果正确性 / 表述清晰性，逐条对照实名评委解读）+ 第三层检查项（15 维度适配性 + 16 维度自查表，均已去分值）（对照 `references/论文自评表.md`）

**通过标准**：以上 7 项全绿（含三层自评）。只指出差距项附事实依据，不给改法。

## 门禁5 process_record（主 Agent 产出 → output/process_record.md）

独立 Subagent 对照 `methodology/process_record规格.md` 终审：

- [ ] ≥500 行，13 节齐全、每节有实内容（非填空）
- [ ] 每问试错链六步完整：怎么想 → 试了什么 → 结果如何 → 在哪撞墙 → 怎么改进 → 最终效果（真实失败详记，未发生如实注明）
- [ ] 算法心路详规：候选清单 → 逐候选评价 → 淘汰理由 → 选中理由 → 比较表 → 验证逻辑链
- [ ] 文献借鉴节：逐篇文献"来源 + 参考了什么（模型/算法/论证/写法具体到哪部分）+ 怎么用 + 效果"写清楚（写透级，对应规格 §5.5）
- [ ] "为什么选这个模型"推导完整（核心建模选择论证）
- [ ] 摘要每个数字反向溯源到 results/ 字段
- [ ] 基于执行 Agent 试错日志 + 审查日志整合，禁止编造

**通过标准**：以上 7 项全绿。
