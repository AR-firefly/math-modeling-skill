# 去 AI 味写作（v3.0，写作质量加强）

> 现行阶段、来源、创新、人工声明及交付边界见 `执行与交付契约.md`；原细则在当前阶段范围内执行，不代替团队第一问批准或全文独立终审。

> 论文读起来"像 AI 写的"会被评审直觉降档——AI 痕迹是套话和空转，不是内容问题。
> 本文件列八类高频 AI 痕迹，每类给识别特征 + 改法示例。**写作心法四轮自审第三轮用它逐条扫描。**
> 定位：这是**加强表面**（论文表述），不改 skill 内核——AI 依然透明做保底初稿，这里只管让初稿读起来是"人写的、有依据的"。

## 八类 AI 痕迹

### 1. 句式模板化（"首先/其次/最后""综上所述"连环）

**识别**：段落全是"首先我们…其次我们…最后我们…"，连接词不带信息。
**改法**：砍掉一半连接词，让内容自己说话；结构靠逻辑不靠套话。

```
✗ 首先我们对数据进行了清洗，其次建立了优化模型，最后求得了最优解。
✓ 数据清洗后发现某字段缺失率 18%，据此在模型约束中加入了…（直接进入内容）
```

### 2. 空洞结论（"本模型有效可行"无数据支撑）

**识别**：结论句全是形容词，没有一个数字、一个对比。
**改法**：结论必须带可核对的量化结果。

```
✗ 结果表明本模型具有良好的求解性能。
✓ 本模型 500 次随机算例平均求解时间 2.3s，较基线提升 12.68%（结果来自 results/Q1_…）。
```

### 3. 空洞连接词（"值得注意的是""不难发现"）

**识别**：这些词后面没有"值得注意的"信息，是纯填充。
**改法**：删掉。如果后面真有不寻常的点，直接说那个点。

```
✗ 值得注意的是，本文采用了一种较为新颖的方法。
✓ 本文改用分阶段求解：先粗搜定位区间，再精搜收敛，避免了单阶段网格爆炸。
```

### 4. 数据罗列无解释（贴一堆数没解读）

**识别**：表/图后面跟着"如表所示"却没有"这说明什么、为什么"。
**改法**：结果三段式——是什么（一句话）→ 为什么（联系模型机制/数据特征）→ 对赛题的意义。

```
✗ 表2给出了各方案的总成本，分别为 3.24、2.83、4.01 万元。
✓ 表2显示改进方案总成本 2.83 万元，较基线降 12.68%——因为新增了…约束，把运输与仓储的耦合成本压了下来。
```

### 5. 公式教科书味（抄通用公式不适配问题）

**识别**：公式符号跟本题变量对不上，像从教科书搬的。
**改法**：从问题第一性原理推导，公式符号对应本题实际量。

```
✗ min Z = Σcᵢⱼxᵢⱼ（未说明 c、x 在本题为谁）
✓ min Z = Σₓ Σᵧ c(x,y)·d(x,y) · p(x,y)，其中 x,y 为调度班次，c 为每班空驶成本（元/km·班）…
```

### 6. 重复同义（同一意思换词反复说）

**识别**：一段里"提升性能""改进效果""优化结果"反复出现，都是同一件事。
**改法**：保留最有力的一个说法，其余删。

```
✗ 本方法提升了求解效率、改进了计算性能、优化了运行效果、加快了收敛速度。
✓ 本方法使平均求解时间降低 40%（其余都是重复）。
```

### 7. 绝对化表述（"显著优于""完美解决"无对比）

**识别**："显著""完美""最优"没有对比实验支撑。
**改法**：改"在 X 条件下优于基线 Y"；没对比就别说绝对词。

```
✗ 本算法显著优于现有方法。
✓ 在本赛题 3 个算例上，本算法较最近邻基线平均缩短 8.4%（对比见 §5.3）。
```

### 8. 情感词/浮夸（"极大地""很好地"）

**识别**："极大地提高""非常好地解决"这类主观程度词。
**改法**：删掉程度副词，保留事实。数据自己说明。

```
✗ 极大地提高了模型的实用价值。
✓ 模型输出与实测数据的相对误差 <3%，满足工程应用要求。
```

## 使用

- 交付前四轮自审（写作心法.md）**第三轮**逐条扫描以上 8 类
- 每发现一处：标出类别 → 按改法替换 → 复核数据准确性（数字仍从 results 来，verify 兜底）
- 去 AI 味 ≠ 削弱内容：AI 仍透明做保底初稿，这里只是把表述从"机器腔"改成"人有据地讲"
