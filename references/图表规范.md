## 一、选图决策表

| 数据形态 / 要表达什么                     | 图类型                      | 何时用                                                         | 例子                    |
| ----------------------------------------- | --------------------------- | -------------------------------------------------------------- | ----------------------- |
| 连续时序（x 为时间/序号，取值多）         | **折线图** line             | 变化趋势、收敛曲线                                             | 迭代收敛、时间序列      |
| 分类对比（x 为类别，取值少）              | **柱状图** bar              | 不同方案/类别的数值对比                                        | 各算法效果对比          |
| 两连续变量关系                            | **散点图** scatter          | 相关性、聚类分布                                               | 相关性分析、Pareto 前沿 |
| 分类 × 连续（分组数值）                   | **箱线图** box              | 多组分布对比、离群点                                           | 多组误差对比            |
| 矩阵/二维数据                             | **热力图** heatmap          | 相关矩阵、网格密度                                             | 相关系数热图            |
| 单变量分布                                | **直方图** hist             | 数据分布、频数                                                 | 误差分布                |
| 数值带误差（均值±标准差（标明误差定义）） | **误差棒** errorbar         | 灵敏度扫描、元启发式 3 次均值±标准差（标明误差定义）、对比验证 | 五样检验结果图          |
| 参数响应曲面                              | **等高线** contour/contourf | 机理题参数扫描、目标函数曲面                                   | 参数对结果影响          |
| 多指标综合评价                            | **雷达图** radar            | 评价类多方案多指标对比                                         | TOPSIS/熵权结果         |
| 预测区间/置信带                           | **区间填充** fill_between   | 预测区间、置信带                                               | 时间序列预测带          |

> **decide_kind 局限**：`Visualizer.decide_kind` 自动判定仅覆盖 line/bar/box/hist 四种。
> 其余（scatter/heatmap/errorbar/contour/radar/fill_between）**显式指定** `kind`，示例见 `references/图契约.md` §七。

## 二、硬性格式（评审必查）

| 项       | 要求                                               | 检查                                                                    |
| -------- | -------------------------------------------------- | ----------------------------------------------------------------------- |
| 分辨率   | **300dpi**（Visualizer 默认）                      | 图中文字清晰不糊                                                        |
| 编号     | 图题**在图下**，表题**在表上**；编号与正文一一对应 | `verify_figure_references` 机器检查                                     |
| 中文字体 | SimHei/微软雅黑（Visualizer 自动探测），负号正常   | 中文不乱码、负号不显示为方框                                            |
| 文件命名 | `save_name` 与正文编号对应（fig1/fig2...）         | 可反向溯源                                                              |
| 配色     | 受控语义色，禁 rainbow/jet/hsv                     | `validate_figures.py` 机检禁 rainbow/jet/hsv；语义色/灰度可读靠人工看图 |

## 三、受控配色与视觉参数（v3.0 合并 §3.1–§3.4）

### 3.1 语义色（首选，权重最高）

- **语义色**：蓝 = 本文方法 / 红 = 基线 / 绿 = 改进（`PALETTE`），配合"基线对比"叙述
- 同一方法跨图同色；类别多按 `PALETTE`/`OKABE_ITO` 顺序扩展
- 柱图用 hatch（`///`）保证**灰度打印可区分**；误差棒必须带 capsize
- 柱图原则从零起；折线等可合理缩放并明确刻度，断轴须说明，不夸大差异。

### 3.2 连续色板（热力图 / 等高线 / 3D）

| 场景             | 首选               | 次选             | 禁用                      |
| ---------------- | ------------------ | ---------------- | ------------------------- |
| 连续单值         | `YlGnBu`/`viridis` | `plasma`/`magma` | `jet` / `rainbow` / `hsv` |
| 双向（相关系数） | `RdBu_r`           | `coolwarm`       | `RdYlGn`（红绿语义颠倒）  |
| 双向（残差）     | `RdBu_r`           | `BrBG`           | `spectral`                |
| 地形 / 海拔      | `terrain`          | `gist_earth`     | `rainbow`                 |
| 分类 3–8 类      | `Set1`/`Set2`      | `Dark2`/`tab10`  | `rainbow`                 |
| 分类 >8 类       | `tab20`            | —                | 彩虹渐变                  |

> 禁 `rainbow`/`jet`/`hsv` 是**硬性**（`validate_figures.py` COLOR-MAP 机检 FAIL）：感知不均匀 + 灰度失真 + 色盲不可辨。
> 连续色板要求 `colorbar` 必带**单位**；双向数据须 `center=0` 且 `vmin/vmax` 对称。

### 3.3 线宽 / 标记 / 误差棒

| 元素          | 参数                                                                  |
| ------------- | --------------------------------------------------------------------- |
| 主线          | 1.5–2.0 pt（`_apply_style` 用 2.0）                                   |
| 网格 / 参考线 | 0.5–0.6 pt                                                            |
| 轴线          | 0.8 pt（`axes.linewidth`）                                            |
| 标记大小      | 4–8 pt（`lines.markersize` = 7）                                      |
| 误差棒        | `capsize=4`、`elinewidth=1.2–1.5`、`capthick=1.2–1.5`；颜色同系列稍浅 |

**多系列标记组合**（避免只靠颜色区分）：

| 系列数 | 标记                   | 线型                    |
| ------ | ---------------------- | ----------------------- |
| 1      | ● 圆点                 | 实线 `-`                |
| 2      | ● + ■                  | 实线 / 虚线 `--`        |
| 3      | ● + ■ + ▲              | 实线 / 虚线 / 点线 `:`  |
| 4      | ● ■ ▲ ▼                | 4 种线型                |
| ≥5     | 区分标记 + 线型 + 颜色 | 按 `OKABE_ITO` 顺序扩展 |

### 3.4 字号与网格

| 元素           | 字号                      |
| -------------- | ------------------------- |
| 主标题         | 12 pt（`axes.titlesize`） |
| 轴标签         | 11 pt（`axes.labelsize`） |
| 刻度标签       | 10 pt                     |
| 图例           | 10 pt（`font.size` 继承） |
| 正文级全局字号 | 10.5 pt（`font.size`）    |

> **≥10pt 是硬性下限**：`validate_figures.py` FONT-SIZE 对 `rcParams` 与轴标签级字号 <10pt 判 FAIL。
> 图内局部标注（`text`/`annotate`/`clabel`/刻度标签文字）按设计可用 8–9pt，机检已排除该范围，不算违规。

- **网格**：默认**无网格**（`axes.grid=False`，靠稀疏刻度引导）；需要时只开 major grid，`ls="--"`、`alpha=0.4`、`linewidth=0.5`，并 `set_axisbelow(True)` 压到数据下方
- **边框**：去上/右 spine；左/下 spine 用淡灰，不喧宾夺主
- **图例**：无边框（`frameon=False`），位置优先右上/图外，**不遮挡数据**，面积不超过图区 25%

## 四、与论文的衔接

- **图分类四类**：诊断图（过程/探索，按验证价值选择正文、附录或过程记录）/ 对比图 / 论文图 / 附录图——画前先定（见 `references/图契约.md` 图分类四类）
- 每张图落盘 `figures/`（300dpi PNG），经 `build_paper_content` 的 `images` 字段嵌入论文
- **图契约登记**：`register_figure(no, title, conclusion, data_source)` → `figures/figures_manifest.json`（核心结论 + 数据出处，防"为画而画"）
- **图号引用检查**：`verify_figure_references`（run_pipeline 渲染后自动跑）——图号连续、正文引用对应、图文件存在；issues 列入 process_record 人工审核
- 图上要有：标题、坐标轴含义与单位、必要图例；数据都要有出处（对应 results/ 字段）
- 图表服务于结果解释与证据表达，宁可少而精，不要多而糙

## 五、QA 校验（交付前）

**责任人**：绘图脚本是**作图 Agent** 写的 → 由**作图 Agent（主责）**在门禁2b 前对 `figures/` 绘图脚本跑
`validate_figures.py` 并修掉 FAIL、逐图完成目视检查；**审查 Agent（复核）**在门禁2b 独立审计，
**必须独立看图**（不得只看作图 Agent 记录），并在 `docs/log_审查.md` 写下作图 Agent 记录中未出现的观察项。

> v2.0 的责任人是「编程手（主责）+ 论文手（复核）」；v3.0 起作图独立成角色，责任随之转到**作图 Agent + 审查 Agent**。
> 编程手职责收窄为「提供 results 数据入口与**算好的误差数据**」——误差棒数值由编程手算好落盘，作图手只读不算。

```bash
python scripts/validate_figures.py <绘图脚本>.py   # 静态预检（中文字体/禁rainbow/DPI≥300/采样记录）
python "<SKILL_ROOT>/scripts/stage_gate.py" --project "<赛题目录>" --stage q1   # 脚本独立运行 + 数值一致
```

- FAIL 必须修；WARN 人工确认；`--strict` 把 WARN 也算不通过
- 每张图必须**实际打开看图**（布局、重叠、裁切、灰度可辨、色盲可辨、中文无乱码），不能只跑脚本就交付
- 脚本硬规范 / 状态机 / 目视检查清单 / 诚实边界，权威在 `references/作图契约.md`
