# 改图指南（模板）

> 本文件是**每道赛题项目内的模板**：项目启动时复制到 `figures/改图指南.md`，由**作图 Agent** 在每新增/修改一张图后同步维护。
> 目的：让"改一张图"变成一个**可对照、可复现、可复核**的动作——不靠记忆，不靠翻脚本猜。
> 配套：`作图契约.md`（脚本规范 / CONTRACT / 状态机）、`图表规范.md`（怎么画）、`执行与交付契约.md` §3（交付物）。

---

## 一、怎么用

1. **新建图**：写脚本 → 填 CONTRACT → 跑脚本 → 在下方总表加一行 → 目视检查 → 更新 manifest 状态
2. **改现有图**：按总表定位脚本与数据字段 → 改 → **重跑脚本** → **重跑 `stage_gate`** → 更新 `artifact_hash` 与状态 → 重做目视检查
3. **改完必做**：`artifact_hash` 三元组（脚本 / 数据入口 / PNG）任一变化 → manifest 状态**自动退回 `pending_verification`**，必须重新走 `reproduced` → `verified`

> **两条铁律**
>
> - 改图**必须重跑脚本**，不能只改 PNG 或只改 manifest。
> - 改图**必须重跑 stage_gate**，否则"图的数值 = results 的数值"这一条没有被重新证明。

---

## 二、图总表（每图一行，改图前先看这里）

| 图号 | 脚本（相对项目根）             | 数据入口（相对项目根）        | 绑定的 results 键（来自 `CONTRACT.data_binding.bindings`） | 状态         | `artifact_hash` 前 12 位 | 备注           |
| ---- | ------------------------------ | ----------------------------- | ---------------------------------------------------------- | ------------ | ------------------------ | -------------- |
| fig1 | `figures/scripts/fig01_xxx.py` | `figures/data/fig01_xxx.json` | `y → Q1_基线_耗时`；`yerr → Q1_基线_耗时_std`              | `verified`   | `a1b2c3d4e5f6`           | 论文 §4.2 引用 |
| fig2 | `figures/scripts/fig02_yyy.py` | `figures/data/fig02_yyy.json` | —（示意图 `kind: "schematic"`，无数值比对）                | `reproduced` | `0f9e8d7c6b5a`           | 方法学流程图   |

**列的含义与来源**

| 列                | 从哪来                                                                                       |
| ----------------- | -------------------------------------------------------------------------------------------- |
| 图号              | manifest 的 `no`（`figN` 纯编号，全文连续）                                                  |
| 脚本 / 数据入口   | manifest 的 `script` / `data_entrypoint`（**相对项目根**，正斜杠）                           |
| 绑定的 results 键 | 脚本内 `CONTRACT.data_binding.bindings`（**左值=绘图参数名，右值=results 键名**）            |
| 状态              | manifest 的 `evidence_status`（`incomplete`/`pending_verification`/`reproduced`/`verified`） |
| `artifact_hash`   | `sha256(脚本 + 数据入口 + PNG)`                                                              |

> 状态与哈希口径见 `作图契约.md` §七。`verified` **只能由审查 Agent 写**。

## 三、重跑命令（照抄，改路径即可）

```bash
# 1 只重跑这一张图（空 cwd 下也应跑通——脚本用 __file__ 自定位）
python figures/scripts/fig01_xxx.py

# 2 静态预检这一张图的脚本（字体 / 禁 rainbow / DPI / 采样）
python "<SKILL_ROOT>/scripts/validate_figures.py" figures/scripts/fig01_xxx.py

# 3 重跑阶段门禁（脚本独立运行 + 数值一致 + 日志结构）
python "<SKILL_ROOT>/scripts/stage_gate.py" --project "<赛题目录>" --stage q1
python "<SKILL_ROOT>/scripts/stage_gate.py" --project "<赛题目录>" --stage final

# 4 全文阶段：图号连续 / 正文引用对应 / 图文件存在
python "<SKILL_ROOT>/scripts/gate_audit.py" --project "<赛题目录>"
```

> `<SKILL_ROOT>` = skill 安装目录。**不要复制脚本进项目**，一律用 Skill 脚本绝对路径调用。
> `stage_gate.py --stage q1` 只依赖 `docs/log_*.md` + `figures/` + `results/q1_results.json`，**第一问即可跑**，不依赖任何全文产物。

## 四、改图影响面清单（改前先过一遍）

| 改动                   | 会不会退回 `pending_verification` | 还要连带改什么                                                  |
| ---------------------- | --------------------------------- | --------------------------------------------------------------- |
| 改脚本绘图逻辑         | **会**（脚本 hash 变）            | 重跑图 + 重跑 stage_gate + 更新总表哈希 + 重做目视检查          |
| 改数据入口 json        | **会**（数据 hash 变）            | 同上                                                            |
| 重跑生成不同 PNG       | **会**（PNG hash 变）             | 同上；**审查侧哈希对不上 → 检出**                               |
| 只改 `CONTRACT` 映射   | **会**（脚本 hash 变）            | 重跑 stage_gate 验证映射成立                                    |
| 只改图题/图注文字      | 不退回（PNG 与脚本未变）          | 同步论文正文引用与 `conclusion` 字段                            |
| 只改 manifest 状态手写 | —                                 | **禁止**：`reproduced` 由脚本自写，`verified` 只由审查 Agent 写 |

**跨文件连锁**：图号变化要同步 ①manifest `no` ②论文正文引用 ③`verify_figure_references`；图文件变化要同步论文 `images` 字段嵌入路径。
