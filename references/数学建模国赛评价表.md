# 数学建模国赛（CUMCM / 高教社杯）评价表

> **生成日期**：2026-09-06
> **生成方式**：4 路独立检索（官网原文 / 评审规则与获奖机制 / 评委与指导教师经验 / 选手复盘 + 本地资料）→ 交叉比对 → 冲突标注
> **适用赛事**：全国大学生数学建模竞赛（本科组）。**不适用于华数杯、美赛、电工杯**——这些赛事有各自独立的评分框架，混用会直接带偏备赛。
> **一句话结论**：**国赛官方从未公布带分值的评分表。** 公开的最高标准只有《章程》第二条的四条定性原则；具体分值由各评阅组赛前试评后内部制定、不对外发布。网上流传的所有"摘要20分/模型30分"分值表均为非官方推算，本表第六节逐一列出并标注其出处与可信度。

## 〇、可信度分级定义

| 等级  | 含义                  | 判定标准                                                                        |
| ----- | --------------------- | ------------------------------------------------------------------------------- |
| **A** | 官方原文              | 全国组委会（mcm.edu.cn）正式发布文件，本次检索中已打开页面或提取 PDF 原文验证   |
| **B** | 权威个人/机构公开表述 | 有名有姓的组委会成员、教授、赛区组委会公开发表的讲座/报道，可追溯到具体人与 URL |
| **C** | 民间转述              | 自媒体、论坛、机构营销文、团队自估，作者身份或数据无法溯源                      |
| **D** | 已证伪/不采信         | 与官方原文冲突，或文中存在可验证的事实错误                                      |

## 一、核心结论：国赛评分的"公开边界"

| 项目             | 事实                                                                                                                                                 | 等级                                   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| 官方评价维度     | 假设的合理性、建模的创造性、结果的正确性、文字表述的清晰程度（定性，无分值）                                                                         | **A**                                  |
| 官方分值表       | **不存在。** 全部官方文件中未见任何分值/权重表                                                                                                       | **A**（已核实）                        |
| 分值怎么产生     | 评阅组赛前对赛题与评阅要点充分讨论，"在达成共识的基础上确定**可操作的评阅细则**"——细则内部掌握                                                       | **A**                                  |
| 计分形式         | **官方未公开具体分制**——"百分制"之说在章程/赛区规范/全国评阅规范中均未出现，属民间推定；官方可确认的只有：**多评委独立打分**、**评分录入计算机系统** | **C**（分制）/ **A**（多评委独立打分） |
| 选手能否看到打分 | 赛后可下载含专家意见的评阅反馈；但细则本身不公开                                                                                                     | **C**（仅选手帖提及，未找到官方实例）  |

> ⚠️ **定标尺的正确姿势**：不要去找"官方分值表"（不存在），而是对照官方四维度 + 官方硬门槛（第四节）+ 实名评委反复点名的扣分点（第五节）。这三层是唯一的硬依据。

## 二、主表：评价维度 × 权重/分值 × 评分要点 × 来源

### 2.1 官方四维度（唯一公开的评价框架）

**来源原文**："竞赛评奖以**假设的合理性、建模的创造性、结果的正确性和文字表述的清晰程度**为主要标准。"
**出处**：《全国大学生数学建模竞赛章程（2023年修订稿）》第二条
https://www.mcm.edu.cn/html_cn/block/44e92058f537729c6b6a62a3662ee417.html｜**等级 A\*\*

| 评价维度         | 权重/分值      | 具体评分要点（来自官方原则 + 实名评委解读）                                                                                                                                                                                                          | 来源                                               | 可信度        |
| ---------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------- |
| **假设的合理性** | 官方未公布分值 | ① 假设**少而精**，每条有实质论证；② **不欣赏罗列大量无关紧要的假设**（谢金星原话）；③ 说明假设成立的物理/现实依据与**失效条件**；④ 随机分布类假设须说明物理实质意义（如均匀分布＝最大熵先验）                                                        | 章程第二条 + 谢金星《数学建模讲座》PPT             | **A** + **B** |
| **建模的创造性** | 官方未公布分值 | ① 特别欣赏**独树一帜、标新立异**，但必须合理；② 与经典/基线方法做**数值对比**证明改进（不是起个新名字）；③ **拒绝套路化**——评价类堆 AHP/熵权/模糊、数据类堆回归/主成分/灰色、算法类盲用遗传/神经网络，会被点名降档；④ 从问题出发，不为用方法而用方法 | 章程第二条 + 谢金星 PPT + 鲁习文（华东理工）交流会 | **A** + **B** |
| **结果的正确性** | 官方未公布分值 | ① **不强调与"参考答案"的一致性，也不强调结果精度**（谢金星原话）；② 好方法的结果一般比较好；③ 结果须符合物理常识（量级/趋势说得通）；④ 答案通常有明确合理范围，方法再合理、偏离该范围也难获大奖；⑤ 须有检验：灵敏度分析、误差分析、稳定性/鲁棒性     | 章程第二条 + 谢金星 PPT + 李波（华中师大）讲座     | **A** + **B** |
| **表述的清晰性** | 官方未公布分值 | ① 摘要应理解为**详细摘要**，独立成篇；② 规范数学语言表达：问题抽象、决策变量、目标函数、约束条件（评委最关注这部分，而非神经网络等工具名称）；③ 图表自解释；④ **严禁暴露身份**                                                                       | 章程第二条 + 谢金星 PPT + 李波讲座                 | **A** + **B** |

## 八、给备赛的三条硬结论

1. **别找官方分值表了**，它不公开。把标尺放在：四维度是否全部覆盖 + 硬门槛是否全过 + 实名评委点名的扣分点是否清零。
2. **2026 年 9 月开赛适用新版 AI 规定**：参考文献前写固定措辞声明，另交 `AI工具使用详情.pdf`（四项内容齐全）。这跟 2025 版要求不同，别按旧攻略准备。
3. **25% 相似度是硬线**，不是建议值。任何"降重到 30% 就行"的说法都与其他赛事口径混淆了。
