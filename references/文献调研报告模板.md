## 七、方法可行性探测（risk probe，选型前必查）

> 方法选中前先探测"放到赛题数据上跑不跑得动、会不会失效"，避免截止前才发现当初看好的方法不能用。
> 借鉴 zhnnky329/MathModeling-skills 的风险探针思想，落进门禁0 载体。

| 子问 | 数据覆盖（有无解） | 规模（能否算动） | 退化风险（输出集中/无变化） | 扰动敏感性 | 结论（可行/需换/需简化） |
| ---- | ------------------ | ---------------- | --------------------------- | ---------- | ------------------------ |
| Q1   |                    |                  |                             |            |                          |
| Q2   |                    |                  |                             |            |                          |

- **数据覆盖**：赛题数据是否覆盖方法所需的输入（缺列/缺历史/缺约束怎么补）
- **规模**：问题规模 n 与方法复杂度，估算能否在 72h 内算动（算不动 → 简化或降精度，须建模手同意）
- **退化风险**：方法在赛题数据上输出是否可能集中/无变化（如所有方案得分相同 → 方法失效信号）
- **扰动敏感性**：参数扰动 ±10% 下结果是否稳定（不稳定 → 灵敏度检验重点，或换更稳方法）

## 八、阅读证据与评分用途

六维分数仅为内部候选文献排序，不能替代来源准入、方法正确性或论文评分。匹配优秀论文须阅读全文，分段记录页码/章节、可借鉴内容和当前论文差距；扫描件查看原页，未读部分标未完成。引用原始方法须确认实际阅读内容，不从参考列表直接搬运未核验引用。
