# 终审运行检查表（固定内部质量标准）

原始评价表保留供核对，不把民间评分当官方。官方硬要求按比赛年份及原始发布页面复核，经验建议注明性质，C/D权重不用于打分、优化目标或通过判定。此表为内部质量标准，不承诺实际奖项。

| 项目 | 必审证据 | 不通过示例 |
| --- | --- | --- |
| 题意与模型 | 全题依赖、假设依据/失效条件、模型公式、替代方案比较 | 把算法名当模型，假设决定结果却不论证 |
| 算法 | 步骤/伪代码、参数、复杂度、实际代码与运行证据 | 演示函数代真解，只有方法名称 |
| 数值与解释 | 指标身份、单位、条件、量级趋势、实际意义 | 标签互换，数值虽对但解释相反 |
| 检验与灵敏度 | 五类适用性及独审N/A理由、真实模型重算、关键与联合参数 | 套演示检验、用勾号代数值证据 |
| 摘要 | 明确所建模型、求解算法、各问结果及意义、验证结论 | 空泛有效性判断，无模型或关键数值 |
| 文字图表 | 各自自足、图表有正文解释且互补 | 无对象单位条件，正文只说见图 |
| 绘图复现 | 官方示例/API与发布者依据、代码/数据入口/版本/种子、图片重建 | 只有图片，来源第三方或脚本不可运行 |
| 参考与引用 | 允许原始来源、真实书目信息、正文列表对应、核验状态 | 网络失败记通过，引用未读内容 |
| 优秀论文 | 匹配理由、全文阅读记录及页码/章节、具体差距 | 首段索引冒充全文，扫描件未看 |
| TRIZ与创新 | 使用时机、数学变化、约束、基线对比、副作用 | 逐问强制创新、无收益强行保留 |
| 真实过程 | 13节至少500行，候选对比、真实实验/失败修正、逐篇借鉴 | 编造失败/凑行数，缺关键依据 |
| 人工边界 | 第一问真实批准及版本；AI声明/详情空白；独立人工待办 | AI自批，自动声称人工核验 |
| 实际文档 | 当年格式、身份清理、最终渲染和可编辑源码 | 只验结构JSON不看交付文件 |
| 双审闭环 | 主Agent自审+独立Agent审查，问题/修复/重算/复审证据 | 自评分替代改进，缺独审、降标准通关 |

逐项记录问题ID、标准、文件/页码/字段证据、影响、修复、重算范围、复审结果。全文完成后从评委角度问“为什么还不足以给国奖”，按固定标准循环直至问题关闭或依据事先适用性规则经独审认可N/A。不设轮数，不修改低标准换通过。缺资料/资源/独审或需团队决定则保持未通过并报告。

第一问阶段只审全题理解与第一问范围，其余未授权求解不伪造。最终全文阶段检查所有问题及完整过程记录。机器检查不证明语义正确或获奖资格，独审和自审均必须真正执行。
