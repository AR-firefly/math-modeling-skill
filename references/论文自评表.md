> 现行阶段、来源、创新、人工声明及交付边界见 `执行与交付契约.md`；原细则在当前阶段范围内执行，不代替团队第一问批准或全文独立终审。

> **本表是门禁4 的自评与独审依据**（三层自评 + 优秀论文横向对照）。论文手交付前**逐条自评**，审查 Agent 独立复核。
> **来源**：第一层与第二层出自 `数学建模国赛评价表.md` §四 / §2.1（A 级官方 + B 级实名评委）；第三层出自资料④（15 维度）与资料⑤（16 维度），**已按 C10 去分值、去页数/字数/数量硬指标**。
> **本表不含什么（排除项，不得混入）**：**任何分值或权重**（假设 15 / 创造性 25 / 结果 25 / 表述 35 等一律不采，评价表 §6.2 判定为民间推算且六版本互不一致）、**正文页数下限**（官方只规定「不超过 30 页」，无下限）、**公式/图片/表格数量指标**、**摘要字数硬区间**、**获奖等级预测**（评价表 §七 已列「可溯源的真实评委打分表实例：未找到」，无稳定判据）、**用文风反推「人工参与比例」**（评价表 §四.2 自认「技术上没有稳定判据」）。

## 一、怎么用

1. **论文手**：交付论文前逐层过一遍，第一层**有任何一项不过即停**（一票否决），不进入第二、三层；三层都过再交门禁4。
2. **审查 Agent（门禁4）**：不看论文手结论，独立按本表复核；结论只写「通过项 / 差距项（具体文件·位置·现象）/ 通过与否」。
3. **判断口径**：每条只给三档，**不给分、不加权、不折算总分**——`✅ 合格` / `⚠️ 存在问题` / `❌ 严重问题`。存在 ❌ 即不通过。
4. **第一层的 ✅ 需要证据**，不能只写「已做」：查重报出实际相似度、声明与详情 PDF 实际存在、页数实际点数、附录源码实际可运行。

## 三、第二层：官方四维度

> **唯一公开的评价框架**。《全国大学生数学建模竞赛章程》第二条原文：「竞赛评奖以**假设的合理性、建模的创造性、结果的正确性和文字表述的清晰程度**为主要标准。」（评价表 §2.1，**A 级**）
> **官方未公布任何分值或权重**，各评阅组赛前自行制定内部细则、不对外发布。因此本层**只做定性对照，不打分**。
> 下表「评分要点」逐条对照**实名评委解读**（谢金星 清华·组委会秘书长 / 鲁习文 华东理工 / 李波 华中师大，评价表 §2.1，**B 级**）。

| 维度                   | 对照要点（官方原则 + 实名评委解读）                                                                                                                                                                                                                      | 自评 | 差距位置 |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- | -------- |
| **① 假设的合理性**     | 假设**少而精**，每条有实质论证；**不欣赏罗列大量无关紧要的假设**（谢金星原话）；说明假设成立的物理/现实依据与**失效条件**；随机分布类假设须说明物理实质意义（如均匀分布＝最大熵先验）                                                                    |      |          |
| **② 建模的创造性**     | 特别欣赏**独树一帜、标新立异**，但必须合理；与经典/基线方法做**数值对比**证明改进（不是起个新名字）；**拒绝套路化**——评价类堆 AHP/熵权/模糊、数据类堆回归/主成分/灰色、算法类盲用遗传/神经网络会被点名降档；**从问题出发，不为用方法而用方法**（鲁习文） |      |          |
| **③ 结果的正确性**     | **不强调与"参考答案"的一致性，也不强调结果精度**（谢金星原话）；好方法的结果一般比较好；结果须**符合物理常识**（量级/趋势说得通）；答案通常有明确合理范围，方法再合理、偏离范围也难获大奖（李波）；须有检验：**灵敏度分析、误差分析、稳定性/鲁棒性**     |      |          |
| **④ 文字表述的清晰性** | 摘要应理解为**详细摘要**、独立成篇；规范数学语言表达：问题抽象、决策变量、目标函数、约束条件（**评委最关注这部分**，而非神经网络等工具名称）；图表自解释；**严禁暴露身份**                                                                               |      |          |

### 5.2 支撑材料：`AI工具使用详情.pdf`

**仅在使用了 AI 时提交**。四项内容缺一不可：

| #   | 内容                                     | 写法要点                                                                                                    |
| --- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| ①   | **工具名称与版本**                       | 逐个列出（如某模型某版本），版本号须可核对                                                                  |
| ②   | **使用目的和环节**                       | 对应到具体环节：文献调研 / 建模 / 编程求解 / 作图 / 论文写作 / 审查——写"用来做什么"，不写"提供辅助"这类空话 |
| ③   | **主要提示方式与使用过程**               | 写清怎么问、怎么迭代；**可附典型交互示例**                                                                  |
| ④   | **对 AI 输出的采纳、人工修改和核验情况** | 哪些采纳、哪些改了、怎么核验的                                                                              |

> ⚠️ **「语言润色除外」是实质限定**——**纯语言润色不计入需报告的 AI 使用**。这一条必须写到，否则会把正常的润色误判为违规。判据是"是否影响建模与分析的实质内容"，不是"是否碰过语言"。

### 5.3 违规红线（一票否决）

- 不符合上述要求 **视为违规**；
- **故意隐瞒、虚假声明、或把未经审查核实的 AI 内容作为核心建模成果提交 → 取消评奖资格**；
- 核心建模与分析**必须由参赛队主导**（第一层第 7 条竞赛纪律同源）。

### 5.4 留空约定（AI 与人的边界）

- 论文内声明正文、`AI工具使用详情.pdf` 正文**一律留空**，由人填写；
- AI **只**做两件事：① 在 `output/paper.tex` 的参考文献之前**预留正确位置**（含小标题占位）；② 在 `output/process_record.md` 与 `output/risk_points.md` 中**列明格式要求与四项内容清单**，并作为独立人工待办提示；
- AI **不得**代填、不得预先勾选、不得在验收时声称"AI 声明已完成"。**AI 交付完成 ≠ 团队可提交。**
